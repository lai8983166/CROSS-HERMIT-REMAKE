# 多块真实文字纹理（2026-10-13）

新的32位辅助程序独立保存最多10块真实Direct3D8纹理，每块拥有尺寸、锁定状态、真实指针、vtable和方法地址。单次会话最多创建32块；释放后的地址记录在有界退役集合中，驱动若复用这个地址，新对象也被拒绝，避免旧裸指针重新获得有效身份。旧单纹理辅助程序和旧证据不改。

每个请求按实际指针查询对应对象，完整缓冲长度来自该对象的实际pitch和height。锁定一个对象不会改变另一个对象的锁定状态或缓冲。无效、外来、已释放、重复锁定、错误格式/尺寸/缓冲和超出容量的请求均拒绝。close按创建的相反顺序解锁并释放所有剩余纹理，再释放设备、工厂和窗口，记录每个Release和Unlock结果。

真实平台测试验证两块不同尺寸纹理的独立完整写入/读回、独立锁状态、外来与已释放指针拒绝、退役地址不会重新接纳、10块对象上限，以及多个锁定对象的清理。原单纹理三项测试继续通过。本步骤只是平台所有权扩展，不表示原第二句字体/纹理或GPU绘图已经执行。

Python入口为`tools/school_d3d8_multi_bridge.py`，使用独立构建输出路径。主机设备仍是显式声明的隐藏窗口平台输入，不是原renderer启动。后续原版续跑使用独立的第二句光栅和锁定镜像，保留首句完整实际纹理，不把旧helper输出文件改成新helper。
