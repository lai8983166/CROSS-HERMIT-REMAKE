# 无人工输入的原启动交接

2026-11-07，`connect-terminal-wait-and-battle-exit` 的2.1前置。原启动动画可以自行结束；之前100秒观察没有覆盖它的自然终点。本轮按原字段等待，已经观察到原startup线程退出和菜单独存，不再把用户点击作为此段测试的前提。

## 实际进展与边界

第一例从全新私有进程PID39320开始，总耗时276.329秒。273.281秒时原回调局部计数16205、任务状态100；273.906秒时保留的原worker句柄已signaled，GetExitCodeThread返回0，startup从32桶注册图消失；随后菜单成为唯一注册任务并稳定超过1秒。此时尚未发送观察器的WM_CLOSE。该例262个保留样本、258份TLS样本，压缩来源66,917B。

补齐采集合同后的第二例PID36996在273.500秒采到计数16204/状态100，274.000秒确认原worker退出码0，274.110至275.203秒菜单独存；Job在276.157秒为空，未强制终止。来源67,418B，SHA-256为`799a7fa3f50e29676a4bfaca8ea24689b3f15efe8e908291fb68a802ffadb85c`。两次都是开发观察，不充作两例完整战斗验收。

另须区别观察结束时受保护子进程的退出状态：两例均记录`0xC0000354`，外层父进程为0。这不等于WinMain正常返回；原startup工作线程在WM_CLOSE之前退出码0的证据与之分别记录。

这是采样支持的自然交接观察，不是完整指令/API轨迹。静态原字节说明正常路径会释放启动资源组10、回收PTD/TLS并注销任务；当前采样没有逐项观察全部释放，不据此宣告资源寿命或完整战斗退出通过。也不能用稀疏鼠标快照排除所有外部输入。观察器自身没有输入注入、游戏内存写入或原游戏函数调用。

第一例漏采了部分初始化及dispatch代码的运行时副本，其独立结果明确为`partial_handoff_observation`。第二版补齐这些范围、两个计时IAT槽、原TLS index/扩展指针字节和manager Event身份；版本身份分别验证，不修改第一例报告冒充新实现。

## 为什么等待约四分半

原50649E初始化局部计数；506692每次恢复startup循环加1。stage22在50A00D比较16204，相等后把stage置100并再次yield；下一次循环计数16205，原分派进入自然尾。计数由原调度帧推进，不能按墙钟延迟替代判断。默认QPC节流约60次/秒，调度、声音等待和初始化另占时间；`415480(1,60)`中的60是追帧上限，不是直接设置60Hz。

正常回调返回点是421F8A。原worker421F50直接调用56E1E0(0)结束线程，并不会回到通用CRT wrapper中的56E183执行；采到56E183祖先帧只证明当前调用来源。manager观察原退出、解除注册、析构后，MAIN下一轮才消费event1创建菜单。仅看到待消费event1或瞬时空图都不足以授权新建battle。

## 可复用入口

在项目空闲、短设备预检可用时执行一次有界观察，使用新的输出文件名：

```bash
.venv-audit/Scripts/python.exe -B -X utf8 -m devtools.terminal_startup_handoff \
  --out analysis/terminal-startup-handoff-NEW.json.gz --seconds 720
```

观察器只请求进程读取、查询、复制句柄和同步权限；在暂停原MAIN及startup线程的同一窗口中取图、上下文、回调局部量和TLS/PTD。对重复节点、环、异属manager、异常退出及采集错误立即失败。达到原动画终点、原线程退出码0、唯一菜单稳定1秒后自动结束；最多900秒，不自动重试。

全量8,105个资产仍逐个新鲜哈希，但只引用固定父清单`terminal-scene-preflight-v3-20261107.json.gz`及其SHA，避免每个来源重复保存清单。来源保留采集实现指纹、采前采后原代码/IAT和有界现场。第一版观察器与验证器源码分别压缩封存，用于重现历史版本身份；这两份小源码副本不称为独立容灾备份。

当前验证器CLI严格要求当前采集实现身份，不能直接重验旧v1；旧proof保留其源码归档身份。第二例独立复核命令如下，输出必须使用新名字：

```bash
.venv-audit/Scripts/python.exe -B -X utf8 -m devtools.terminal_startup_handoff_verification \
  --report analysis/terminal-startup-handoff-v2-20261107.json.gz \
  --sha256 799a7fa3f50e29676a4bfaca8ea24689b3f15efe8e908291fb68a802ffadb85c \
  --out analysis/terminal-startup-handoff-proof-NEW.json
```
