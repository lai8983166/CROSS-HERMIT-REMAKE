## 地图纹理与退出表缺口

`453C8A→440F00→440C10` 使用地图纹理记录 `TACT+3EF8+2650C = 0E02A404`。其 `+2C` 纹理指针为零。原 `403910` 在 `403930` 检查后，经 `403936` 返回1，没有发生 COM LockRect；不能把该结果称作设备或纹理接口失败。

原 `440C42` 检查该非零结果，经 `440C5F→424F80` 进入游戏断言路径。由于原 `79A640` 为0，原 `424FA7→56E2E0` 进入 CRT exit 路径。它先真实进入13号锁，然后 `56E3C5` 读取旧退出回调表 `04D686D8`，该地址未保存、也不属于本次新 CRT 堆，所以产生真实未映射读。原栈返回链为：

`56E2F0 → 424FAC → 440C64 → 440F2D → 453C8F → 声明根返回哨兵`。

未修改地图纹理指针、断言开关或旧退出表，未为缺失旧堆映射空页，未替代任何游戏/CRT函数。下一步需要从原地图纹理构造/资源路径恢复有效当前拥有关系；若继续真正的 exit 路径，则还需要完整 CRT 退出表来源，不能把旧表归入新空堆。
