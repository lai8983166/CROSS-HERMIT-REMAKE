# Godot 当前冒险的图形开场

第五周队伍就绪后，进入「必修冒险 · 出发准备」→「查看本关地图」→「开场演出」。现在使用原版人物、边框和姓名，在地图上呈现十段开场文字。

←/→或「上一段/下一段」翻页；空格/Enter在淡入时完成当前显示，显示完成后进入下一段。「显示完整」只结束视觉淡入。Esc先关闭演出、再返回队伍；关闭后地图拖动和缩放恢复。重新打开从第一段开始，演出阅读不写入学校存档、不清除必修限制、不开始战斗。

## 来源与显示

`tools/school_opening_presentation_export.py`读取固定身份的原EXE、T0005脚本、GYBC_00/SC004/SC009资源，导出原版RGB555透明图像及配置4/7/8的图层、边框片、正文/姓名位置。脚本30/43/44/17顺序决定人物切换、文字清空和保留的文字银行；因此会同时看到伊里安、瑟希莉絲和旁白的旧文字，不是单一文本框替换。

运行时只加载小型来源目录和三张PNG，不读取大型审计报告。资源身份、尺寸与目录SHA核对后才打开。1024×768逻辑舞台按可用画面等比适配；中文由Godot Unicode字体显示，21号正文避免原第三句末字孤立换行。字体形状、整张地图背景与导航栏属于重制呈现，不等同于原版GDI位图或战场摄像机。

角色背景60次更新、框延迟30后淡入45次、文字24次的透明度使用来源整数截断。图层5的关键透明度/姓名显现点与已有原版动画记录核对，第三句透明度与原版真实文字等待记录核对。测试专用期望只存有限的捕获值，运行时不加载它。演出使用显式本地60Hz视觉时钟，大帧间隔有上限；翻页允许结束当前预览显示。

原版隔离执行证明仍只覆盖前三句及已核对的图层过程；其余页面的图层/文本来自原脚本静态投影。这里没有执行完整原VM、世界调度、后继确认/结束事件，未开放实际当前关卡战斗。

## 验证

新窗口测试覆盖十段文字、两个姓名/人物、文字积累与清空、原版透明度、视觉时钟上限、按钮/空格/Enter/方向键/Esc、关闭/重开和学校/存档/gate保留。窗口尺寸覆盖1024×768、1280×800和800×600；捕获的是Godot实际视口，可能与含留边的系统窗口尺寸不同。

最终实际窗口截图在 `analysis/school-graphical-opening-window-final-20261013/`。历史v2保留字体22号时的换行结果；v3修正字号，v4补充时钟检查。原开场预览、地图和出发页的兼容验证保留各自日志。来源图像可在临时目录重新生成并逐字节核对。

本轮验证源码运行，尚未验证独立导出包；地图/既有界面的Image文件读取方式及新来源身份检查仍需在打包阶段统一处理。
