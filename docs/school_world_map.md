# 原版世界计时与地图更新

来源模块 `school_world_map.py` 独立解析固定SHA原EXE，覆盖493630、467B60、46E9C0及地图子函数。计时要求UnitCtrl+108B48为0且108B3A非零；当前开场状态不满足，计时保持。开启的声明探针按原指令计算signed32累计加1、剩余减1及负数归零/返回1。原计时上限比较是signed jg对INT_MAX，任何signed32输入都不能通过，不能按反编译器缺失的分支臆造“无限时不扣减”。
