# 四月第 3 周原档出击

在重制学校点击“原档出击”，选择隔离客体保存的四月第 3 周 v7 学校档。入口验证原文件 SHA-256 后，从五个班的实际槽位读取教师、学生、职业、属性、成长池、装备、技能和班内关系。这个检查点有 35 名在籍学生，出击 20 人。文件位置、来源和摘要见[原版冒险 3 返校记录](m3_adventure44.md)。

MAP03 使用 64 × 96 逻辑格、原图集、42 个原模板与 T0003 对话。目标是歼灭敌军并占领原对象表 5FF760 指定的三处设施（模板 2、3、4）。失守、占领、超时和全倒按 433130 / 4335B0 的分支处理，胜出的三档评级都播放子脚本 5。结算按本场表现、原档班内关系与任务 3 积分表计算经验及 20 人成长包。界面在确认战果后返回学校菜单。原档的持续成长、掉落和第四周返校仍待接入。

无窗口回放从学校档组队，实际移动、攻击并占领至 38 敌全灭，己方零倒下，选择值 1，子脚本 5。1064 条指令共 9795 个逻辑 tick，指令回放 SHA-256 为 b5651dc0e8623f6c15ac9adf0f470c0aa4e07f86620012d9011e17bc2d6d820b。战斗用时 19584 原计时单位，经验 41245 + 40174 = 81419。原版从同档经另一套操作得到 39844，累计 81089。指令、敌方 AI、设施攻防和随机时序尚缺同操作原版对照。回放通过公开战斗指令推进，结果校验覆盖胜负、敌方损失、经验与成长包数量。[回放脚本](../devtools/replay_m3_adventure03.gd)

复现命令使用 Godot 4.7.2，工作目录为项目根目录。
