# 第二个场景单位输入与缓存查询

本轮沿实际学校调用栈从首个NPC的453630返回处继续，执行一次原版451D80加载进度、第二条场景模板的4DA450记录转换和4680B0工作前缀，在4500B0请求加载前停止。原版选择索引248、角色/职业387、类别0、状态1，档案为 `data\DxAnim\51e.bin`，颜色参数0、加载模式0。颜色0在这一分支有明确含义，不能套用首个NPC的第5套外部颜色表。

第二个控制器分配在18000060，独立于已绑定的18000000首个NPC控制器。初始样本使用缓存槽4、纹理计数114，待机与第五班样本使用槽3、计数113；本轮只初始化控制器并发出档案请求，未读取51e档案或完成第二个构造尾部。

进度函数自然调用方为453638，图形绘制、提交和调度分别在451E20、415420、422360作为精确参数的声明边界。原版进度字节算法继续执行。记录阶段只允许第二个176字节记录及原函数所需临时概要区写入；前缀仅允许该单位的1312字节工作区、记录、一个8字节缓存槽、4字节计数器、独立84字节控制器和栈/SEH写入。各阶段比较所有其余映射字节，保护首个NPC、当前队伍、资源、地图和持久数据。

上游地图资源遍历使用有限的8批执行，时间或指令上限到达时从实际EIP继续，不伪造返回或阶段成功。纹理构造仍在指令钩子退出后执行并恢复整个CPU上下文和栈；原版成功边界、文件关闭和旧写入约束保持。原来的驱动与全部历史证据不修改。

另一个独立驱动直接执行原版466DA0缓存查询。其种子是明确声明的、上一轮初始学校样本在首个NPC前缀完成后的缓存字节，已经包含首个NPC及当前学生单位。驱动按35条原场景模板的职业/颜色键查询：26次命中包含首个NPC的一次复查，余下34个键为25次命中和9次未命中。未命中后的键和不透明控制器整数由驱动显式插入；这些插入没有执行原版分配、资源绑定或单位构造，不能当作实际完整场景循环。

原版缓存查询扫描512个槽，空槽不终止搜索，有效标志为任何非零字节。职业字段以有符号16位、颜色字段以有符号8位比较，返回首个匹配槽的地址。独立声明的末槽、重复键、失效匹配槽、有符号/无符号区别和满表未命中探针核对这些边界。职业316和317即使选择同一04e档案，也有独立的职业键和颜色参数，不能混用缓存。

独立EXE规则解析记录/工作/控制器初始化、进度和缓存扫描条件，核对完整实际第二个单位输入，以及每一次查询的返回地址、查询前后不变的缓存和声明插入后的全部缓存字节。规则与冻结输出分开导出，坏编码、错误长度、非法查询整数/接收器和不支持的记录/前缀输入拒绝。
