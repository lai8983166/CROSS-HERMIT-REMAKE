## 2. 攻击解算流程 (`488BC0` 主入口)

```
1. 攻击状态填充 488AF0: 快照攻方(4DEAA0 属性 + 46B3E0 地形) → 44B 缓冲
   └ 48A260 武器威力 / 48A380 威力 / 48A730 命中 (按技能模式缩放)
2. 范围展开: 形状 0-4 固定阵型 / 5 = 随机目标(43C1D0 可见性判定) / <0 单体
3. 对每个目标:
   命中判定 = 4824D0(物理) | 4826F0(魔法) | 482810(固定/特效)
   → 482D60 播放命中演出 (48B2E0 效果) → 491EF0 伤害应用
4. 范围内逐目标延迟: 延迟 = 序号×K+10 / 0x8A-距离×K (min 10), K=0x618EE8 系列表值
```

## 3. 伤害公式 (已完整还原)

### 3.1 物理攻击 `4824D0(atk, def)`

```c
// atk: u16[0]=威力 [1]=浮动范围 [2]=命中; [0x14]=伤害输出
// def: +8 回避字节 +0x10 回避系数 +9 防御字节 +0x14 防御系数 +0x24 HP u16

命中残量 c = atk[2] - (def回避 × def系数) / 100 - rand()%100;
if (防方无回避属性(=0) 或 命中残量≥150)
    倍率 m = max(c, 150);          // 命中溢出 → ≥1.5 倍伤害档
else if (rand∈(4,0x5E] 且 c<0)     // → MISS
else m = 100;

威力 p = atk[0] + (atk[1] ? rand()%atk[1] : 0);
伤害 d = p × m / 100 - (def防御 × def系数) / 100;
if (m == 100) { if (d < 1) d = 0; }   // 普通命中可 0 伤
else          { if (d < 1) d = 1; }   // 至少 1
```

### 3.2 魔法攻击 `4826F0`

```c
p = atk[0] + rand()%atk[1];
d = p × (100 - def[0x0A魔抗] + def[0x1C修正]) / 100 - (def[0x0B] × def[0x18]) / 100;
d = max(d, 1);
```

### 3.3 固定/特效 `482810`

```c
d = atk[0] + rand()%atk[1];   // 无减项, 直接输出
```

### 3.4 属性缩放 12 模式 `48A380`(威力) / `48A730`(命中)

技能表 +0x04 / +0x05 选模式, `S[n]` = wk 属性字节 (unit+600 同布局), `B`/`C` = 表中基/系数:

| 模式 | 公式 |
|---|---|
| 0,1 | 不修正 (武器/表值) |
| 2 | 原 + B + S[+4]×C/100 |
| 3 | B + S[+4]×C/100 |
| 4 | 原 + B + **力**[+5]×C/100 |
| 5 | 原 + B + **敏**[+6]×C/100 |
| 6 | B + **敏**[+6]×C/100 |
| 7 | B + **感**[+7]×C/100 |
| 8 | B + **活**[+8]×C/100 |
| 9 | (活[+8] × (活+智[+9]+B)/100) × C/100 |
| 10 | ((活+力+B) × 活/100) × C/100 |
| 11 | ((活+感+B) × 活/100) × C/100 |

注: 模式 2/3 用 +4 字节 (wk 布局 = char_no; 语义存疑, 待对照具体技能数据)。

武器威力 `48A260` (技能表+0x01): 0/1=武器值原样; 2=+表[0x14]+力×表[0x15]/100; 3=+体力同式; 0xFF=固定255。

### 3.5 技能等级三元组修正 `4DEAF0`

```
值[i] += 表[+0x20/0x2C/0x30] + 等级 × 表[+0x2A/0x2E/0x32] / 100   (钳 0~999)
```

### 3.6 恢复量 (unitctrldamage 492C20)

```
恢复 = 表[+0x1C] + 属性(+6) × 表[+0x1E] / 100
```

## 5. AI 架构 (unitctrlai)

### 5.1 行动状态机 `477980` (wk+0x293)

```
0x00 选技能: 46C930 可用性(消耗) → 47BC90 评估 → 不可用则用职业默认攻击(职业表+0x18)
0x0A-0x0C 移动阶段: 476680 子状态机
0x10-0x13 目标复核 / 追击 (职业表+0x1B)
0x14-0x17 施放: 咏唱延迟(帧) → 46BEB0 动画 → 48CCB0 弹道 → 记录回家坐标(职业表+0x16)
0x18 善后: 职业表+0x1D 连锁 / 回 idle / 脱离
任意失败 → 0x0F (回合结束)
```

AI 工作区字段: `+0x293` 状态, `+0x4D0/0x4D2` 目标像素坐标, `+0x4E0` 冷却帧, `+0x4E4` 重试计数(>10 放弃), `+0x4EE` 目标单位ID(-1无), `+0x4F2` 选定技能ID(-1无), `+0x4FA` 次目标

### 5.2 移动子状态机 `476680` (0~0x0A)

```
0: 初始化 → 评估器 47D210 (物理) / 47D570 (魔法) / 47D730 (特殊)
   返回: 1=可直接攻击→3, 2/3=有路→移动, 0/4=无解→冷却
1/2: 备用评估 (重试时参数=1)
3: 47D830 攻击定位确认 → 4 攻击态
4-6: 移动失败重试分支
7: 47D930 路径构建 → 8
8: 47DA30 逐格走 → 0=完成→9, 2=受阻→4 (冷却 30/180 帧)
9: 47DBD0 到位判定 → 47DEC0 细分 (再攻击/换目标/结束→10)
10: 47E2B0 完成回调 → 9
```

寻路: 格坐标换算(像素>>21 / >>20) → `43BFA0` 可通行 → 距离²(dx²+dy²)<100 近距判定 → `findpath.cpp` 建路 (`438AD0/437E40`)

失败冷却: 屏幕外 180 帧 / 屏幕内 30 帧 / 部分完成 60 帧 (`468D80` 判定在屏)

### 5.3 行为开关 (属性块)

`+0x9F` AI 模式: 0/1=待机系, 2=积极 pursuer, 3=坚守; `+0xA0` 次级开关; `+0x9D` 完成标志。
`+0x30` = 地形适应字节 (传入所有寻路/可通行判定)。
