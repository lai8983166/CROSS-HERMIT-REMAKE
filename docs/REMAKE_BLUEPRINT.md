## 1. 游戏循环 (学年日历)

```
月(0x7A528E) × 每月 5 周(0x7A5290 1..5) — 周推进器 4d3510
每周: 5 个项目槽(0x7A5210) 排课[训练/课程] × 每槽 4 名学生
     → 4c00c0 周结算: 逐人 4c0400 (点数入池+技能习得+等级重算)
     → 4d31f0 技能/道具持有关系整理; 4d3e90/4d3510 全员转职资格刷新
战斗周: 载入 MAP 四件套 + T*.BIN 事件脚本 → 实时战斗 → 战利品 4bca40 + 好感度结算 4bf9e0
```
- 剧情推进 = YBC32 脚本 (事件旗标 0x7D4F3C[128]，回想解锁同源)
- **无周目内货币经济**：成长唯一稀缺资源 = 时间 (周数 × 槽位)
- 周目继承 49ee30：能力减半、池反查重建、旗标清零

## 2. 角色数据模型

**存档记录 (0x4A0/人)** — 重制建议改扁平结构，语义如下：
```
职业 u16 (→30 职业表) | 七属性 = {值byte + 成长点池 u32}×7 (力敏感活智耐精)
等级 u8 (派生!) | 装备×8 u16 | 技能×8 u16 | 技能状态 84 槽 (2=新习得/3,5,6=已学)
阵营 u16 | 队状态 84 槽
```

**派生规则 (核心!)**：
```
属性值 = walk(池, 增量表[136])        clamp 1..135 (上限开关 100/135)
等级   = walk(Σ7池 + Σ已学技能的等级点贡献, 等级表[50])   150,000 → 8,500,000
        (级 2→3 仅 +7,209；级 49→50 +776,684 — 前平后陡)
```
值不是独立字段——**存池，值永远查表派生**。这是整个成长系统的支点。

**战备合成 4b93c0** (进战斗前的快照)：
```
HP_max = (耐×3 + 力 + 敏 + 修正A + 修正B) × 职业[HP系数]/100   clamp 1..999
MP_max = (…同构…) × 职业[MP系数]/100                          clamp 30..999
精神系 = (精×3 + 智 + 感) × 职业[精神系数]/100
修正A/B = 装备链(4dcf00) + 技能链(4dd510) → 0x4C 缓冲 38×i16
        ([8]HP [9]MP [0xF]精神 [0x15..17]修正B [0x12..14,1,2]威力 [0x1B]命中 [0x19]射程)
特殊加成 = 0x738998[id] 函数表: 攻击表[+0x20]×属性/100×[+0x22]/100
```

## 3. 成长系统

### 3.1 课程/训练 (唯一成长来源)

**课程表 15 项 × 0x60**：
```
[8×i32 点数包]  id1~5=单属性40,000; id6=精; id7=智12000+精6000; id8=敏智精各5000; id10=全6000...
[+0x42: 11×u8 系别习得率%]  (100=必得; 如 id1 仅重系40%)
缩放: 增量 = 点数包 ×(课程系数+50)/100 ×(参与属性均值+50)/100; 超属性cap部分半数转第8槽
```
**技能习得** (同一次周结算)：
```
候选 = 12×12 矩阵[槽][系别] → 技能id (职业的 11 系亲密度决定各系可学数)
判定 = rand()%101 ≤ 课程[+0x42][系别] 且满足 0x74F686 属性要求
```
**手动加点** (个人画面)：+/- 调目标值，池增量 = 反查(值+Δ)−池，预算 = 距 50 级封顶的余量。

### 3.2 转职 (30 职业)

```
要求: 解锁月/周 + 七属性下限 + 属性和下限 + 前置技能×3 (0x738CD0 表, 步长 0x32)
特例: 剧情'd'旗标强制解锁
执行: 写职业字段 → 重算技能/装备状态 → 演出
```
攻略的"黑白系"= CON75→物理系 / SPI75→魔法系 两种职业行的属性下限。

## 4. 战斗系统 (RT-SRPG)

### 4.1 时间与行动
- **ENGAGE TIME** = `修正h×3600 + 表[lv]×60 + 修正s`，clamp(1, 356,400s)
  表[51] (分钟)：lv1-5=5940(99h封顶) → 3min/级降至 lv20 → 2min/级至 lv50=540(9h)
  **等级越高行动时间越短**——高等级单位是"精而贵"，核心平衡机制
- 施放节拍：前摇帧(攻击表+0x0A) → 效果 → 后摇帧(+0x0E)；AoE 半径 = 表[+0x16]+属性×[+0x17]/100 (cap 32)

### 4.2 伤害/命中 (公式照抄)
```
物理 4824D0: c = atk命中 − (回避×系数)/100 − rand()%100
             c≥150 → m=max(c,150) (命中溢出=1.5倍档); 命中判定失败 → MISS; 否则 m=100
             d = (威力+rand%浮动) × m/100 − (防御×系数)/100; m==100 可 0 伤, 否则至少 1
魔法 4826F0: 抗性 = 100−魔抗+修正
固定 482810
属性缩放: 12 种模式 (48A380/48A730), 威力对 = (属性A+属性B+基数)×属性/100×倍率/100
```
**攻击表 26 字段图** (0x48/条，~360 共享 id): 类别/装备条件/MP/前后摇/命中/半径/瞄准模式0..6/
敌我筛选/命中演出/四组威力对/等级点贡献(+0x40)。射程不在表内（技能附属表 0x6D4E58×7）。

### 4.3 AI
```
行动机 477980: 0x00选技能 → 0x0A移动 → 0x14施放 → 0x18善后
移动子机 476680: 0~0x0A; 评估器 47D210/47D570/47D730
失败冷却: 180/60/30 帧; 重试>10 放弃
职业表 +0x12~+0x1D = AI 性格块 (移动类型/追击/原地攻击/攻击后行动)
```

### 4.4 地图与寻路
```
BIN: [pxW pxH cellW cellH 256 256 pageX pageY] + 3×W×H u16 层 (地形/贴图/物件, 待实机对照)
MAP: 48+ 页 256×256 X1RGB555 纹理图集 (已可整图渲染) + VPT 寻路数据
VPT: 导航图(N节点,float坐标) + 每格→节点id 映射, ×4 冗余工作区
重制: 用 BIN 可行走层重新生成导航网格 (HPA*), 无需解析原格式
```

### 4.5 战后
- 战利品：掉落表 {id,?,权重}×16槽/类 → rand 抽取 → 稀有度 8 桶分装
- 好感度结算 4bf9e0：同职业+1/同阵营+1/跨组−1/固定搭档+1，clamp 1..100
- **战斗不加任何成长点**（剧情旗标/MVP 演出/道具三种产出）
- 联机 (NETKEYWAIT/NETDATA) 建议砍掉
