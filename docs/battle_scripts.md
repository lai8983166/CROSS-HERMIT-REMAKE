# CROSS HERMIT 战斗脚本 (T*.BIN) 操作码档案

> 反汇编器: `tools/ybc32_disasm.py` → `analysis/script_disasm/` (45/45 文件)
> 编码验证基准: 分发器 `4CE8F0` 反编译 + 编译器名表 VA `0x624850` + 处理器逐个反编译
>
> **ADV 扩展 (2026-09-17)**: 同一 VM 也驱动 ADV 事件脚本 `.YBC` (容器/语料统计见 formats.md §3,
> 217 文件 60,879 指令)。操作码集与本表同源, ADV 特有 **op151=FLAG_SET** (4d12d0):
> 全局标志 `0x7D4F3C[idx]=1` (idx 钳 0..0x7F), 事件已读/解锁位。运行加 `-e cp932` 处理日文原版。

## 1. 指令编码

```
[u16 op][u16 adv][payload (adv-4 字节)]
cell = u32: type<<28|value   t2=立即数  t0=变量引用
跳转目标 = 相对代码基 (子记录+code_off);  op19 = END (VM 暂停/块终止)
文本池 = {u32 n; {u16 off; u16 prm}×n; Big5 NUL 串...}   prm>>5 = 話者ID (推断)
```

## 4. 实例 (T0001 开场)

```
00035c: TACTPLAYEREXIT        adv=20  0 0 20 3600        ; 班组0 退场(格20, 帧3600)
000400: BORDPACKONWAIT        adv=20  8 3 0 30           ; 开对话框
00041c: TEXT                  adv=6   #0 "老師……？"      ; 文本池#0, 話者 prm=192(>>5=6)
000422: TEXTWAITKB / KEYWAIT
00042a: BORDONWAIT            adv=16  4 ...
```

每战主循环骨架: APPEARGROUP 出现 → EVENTCELLWRITEPOS 布点 → 对话演出 →
`IFGOTO var[0]==n` 每回合查事件开关 → TACTSETDESTROYSCRIPT 指定破坏迁出 → END
