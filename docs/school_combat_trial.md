# 第五周战斗操作试验（2026-10-14）

入口：学校的第五周「必修冒险 · 出发准备」右上方「战斗操作试验」。当前编班须满足已验证准备条件；无装备的当前学生3/4/9支持，待命学生不出场，教师101仅作为领队显示。入口与旧「队伍操作试验」、独立MAP01「战斗预览」并列，正式「开始战斗」仍禁用。

左键学生/名单选人，左键场景对象查看；右键地面移动、右键敌人攻击。学生会按本地BFS走到来源射程内的可站立格，包含隔水攻击；不必到敌人旁边。攻击显示原版八向施法、攻击和收势帧、HP条及伤害反馈。普通攻击不额外扣MP。中键拖图、滚轮/按钮缩放、「显示全图」「显示阻挡」「查看队伍」「查看敌人」调整视野；空格暂停，S停止当前学生，Esc返回学校。暂停冻结待释放攻击，停止取消攻击。关闭后位置/HP/死亡状态全部丢弃，重开按当前编班与来源初始场景重建。

来源初始场景有11个活动对象，含7个固定位置、移动率0的383号敌人及泉、碑、宝箱、场景角色。重复原版角色号以work实例区分。敌人只在来源射程内按明确的试验调度还击，不追击；24个来源非活动模板不进入试验。场景对象不可控制或攻击。当前学生使用实际学校成长后的属性与HP/MP，118张图像由独立源档案解析，学生调色板已按原版mode2绑定修正为variant3/4/2。

原版攻击/防御快照及伤害标量有实际当前单位的原指令执行核对，详见[攻击输入](school_attack_inputs.md)。四邻格寻路、曼哈顿范围、本地攻击时点、目标调度、HP写入及死亡淡出属于重制试验；原版死亡动画、完整491EF0效果应用、world/AI/事件/波次/通关条件尚未接通。清除初始敌人仅显示试验完成，不发奖、不解除必修限制、不改学校或存档。原版世界当前只新增到4678C0入口前的受限取证，详见[世界准入](school_world_admission.md)。
