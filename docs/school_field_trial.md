# 当前学校队伍的 MAP05 操作试验

2026-10-14：当前实现按来源、独立会话、图形操作与验收分阶段提交。目标是把第五周学生真正放到地图上并接受移动命令；完整必修冒险战斗仍需接敌人调度、波次、伤害与胜负流程。

`tools/school_field_export.py` 从不可变原版 EXE、MAP05.BIN、MAPCOM.BIN 和当前职业的 DxAnim 档案独立导出 `prototype/assets/school_field/catalog.json`。运行时不读原生回放案例，也不拿案例中的出场坐标作配置。任务5的原版配置字节7/8/15提供起点9,16与编队半径5；4225个候选、五元素旋转排列及五种地形移动模式来自已有独立来源解析。全部6144格和所有移动模式逐项验证；构造时已激活的11个场景模板坐标仅作为静态占用边界，不运行或声称完成它们的AI/事件。

学生3/4/9当前对应职业10/6/7，使用 D1A/C1A/E0A 原档案。八向待机/行走由原版动作表、位置表及动画程序解码，角色调色板按原版角色索引选取，依帧mask选择外部或内嵌调色板，共96张实际引用帧。PNG颜色/几何有来源和完整像素SHA；透明度沿用已有DxAnim导出器的索引0透明约定，未声称等于原版GPU最终像素。目录只含来源与明确的重制交互参数，不改变v4十项存档指纹。

来源专项4项通过，包括全部地图/地形/编队输入、原生三种队伍的完整占用格核对、八向程序/调色板/像素、确定性导出和错误来源/调色板拒绝。
