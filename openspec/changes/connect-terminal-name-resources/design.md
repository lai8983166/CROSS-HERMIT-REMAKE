## Context

见proposal.md。前驱55cf784a停在原CreateFontA首指令前；真实GYBC、冷CRT域和队列仍处于当前重建寿命，外层原生调度尚未接通。

## Goals / Non-Goals

本单元完成角色2/1姓名资源链到自然肖像加载入口。保留完整前驱截面及方法输入声明，不将补充析构当作角色任务返回。肖像读取、角色动画、终局退出、显示及奖励不在本有限单元验收中。

## Decisions

- 子类扩展原代码允许集合，复用原守卫/累计摘要算法。只拦截真实Windows/COM叶；CRT复制、路径格式化和游戏函数仍逐原指令执行。
- 当前测量DC由自有离屏GDI创建；首根前声明owner测量DC字段，和设备/门/几何一起列为方法输入。按资源类型投影原生句柄，避免非确定地址污染重放；不在运行期写派生PC/wait。
- 自然字体入口冻结前驱证据，连续完成栅格/上传/原GDI清理后停4CDE10，逐个原栈祖先和SEH保留。当前GYBC和姓名纹理由同一GPU所有者同时持有；源代码/IAT不重绑。
- 独立重新创建GDI绘制三阶段、预测几何/转换并新GPU读回；两新逻辑实例全映射/57项CPU/原摘要精确重放，平台地址字段另按类型核对。

## Risks / Trade-offs

- 本机ACP936解释Big5原姓名可能乱码：保留原字节/实际字体/ACP，独立按相同ANSI合同复现，不擅自转码。
- 原生对象地址不稳定：明确映射类型和所有者，完整记录原生回执，拒绝跨所有者/已释放对象。
- 新资源影响前驱owner字段：首根前输入明确申明，前驱独立验证只在其原不读取测量DC的范围投影该输入，不伪称旧字节原样重放。
- 异常与失败诊断均使用新路径保留，已有报告不覆盖。
