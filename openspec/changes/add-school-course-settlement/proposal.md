# Proposal

## Why

课程已能安排，但学生尚未获得授课成长。接通来源班级记录、点数生成、技能学习及属性/等级重算，让独立课程示例能展示一次真实规则结算。

## What Changes

- 执行来源课程安排后的4A6A10和4BD870/4C0400/4D3600，记录点包、随机学习、属性和等级。
- 增加严格来源规则的纯授课结算模块，核对三门课程、待命/移班、随机种子和封顶反例。
- 独立第4周示例持有学生成长记录，版本守卫下原子结算一次，防止重复增长。
- 课程窗口提供显式结算入口和学生变化摘要；第0周/旧返回会话保留。

## Capabilities

### New Capabilities

- `game-flow/school-course-settlement`: 来源课程点包、技能学习、成长结算和独立示例的一次性发布。

### Modified Capabilities

无。

## Impact

新原指令报告、来源规则和纯模块；扩展新局学校会话及课程窗口。日期/时钟种子输入与呈现边界显式记录。本轮不执行战果确认后字段、实际周推进、剧情或原版存档。
