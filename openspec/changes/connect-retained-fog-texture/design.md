# Design

## Context

父验收6c9ba686...六分支在同一当前资源域执行至原雾层空纹理检查/退出表故障，保留完整开场末端、世界返回和后半段来源。4404A0原初始化将172×128/格式25写入嵌入记录，再4142B0查询设备并调用403BD0；旧阶段仅在该创建函数边界返回，纹理指针仍为0。雾层源缓冲和地图逻辑已存在，不能为了纹理重复整场资源初始化。

## Goals / Non-Goals

Goals: 独立声明缺失的原资源查询/创建根，在有效父资源域创建并保存真实当前雾层纹理；随后同一原普通循环完成原雾层更新/复制/真实上传，尽量接到首个合作等待。记录下一真实未覆盖边界、资源余额和所有补充清理。

Non-Goals: 重复4404A0以覆盖源缓冲，宿主写纹理/地图/门控/断言字段，伪造440563或4539F1调用栈，替代403BD0/403910/56D4D0，旧退出表恢复，等待函数返回代用、真实外层线程、draw/Present、Godot或R3/R6整体完成。

## Decisions

1. 私有继承父生产器/验证器，插入于完整开场结束、普通循环开始和父补充析构之前。先原4142B0查询当前逻辑设备，再以原403BD0根恢复缺失纹理；现有记录尺寸/格式及该ABI必须与4404A0机器码对应。仅声明必要调用栈/寄存器，不覆写游戏派生字段。
   原440547先压入后继创建使用的usage=0，再调用无参数4142B0；该查询裸ret、保留这一个调用者栈字，声明根返回后ESP=STACK+4。第二根明确传device/usage，原403BD0的ret8使ESP=STACK+12。查询根的args字段记录该预置栈字，不把它误作查询函数参数或伪造原440554调用者。
2. 复用已验ImageD3D8助手，新自有GPU域分配独立逻辑地址，原CreateTexture/GetLevelDesc/LockRect/UnlockRect/Release均核完整ABI和当前拥有者。原函数自行更新记录/记账；所有新接口/表面映射必须不与旧区域重叠。
3. 继续原4539B0→世界体→440F00/440C10和后继。逐指令原memcpy、全部CPU/映射/队列/调用链和源雾层缓冲保留；整表面读回与独立逐行复制、未覆盖padding及新GPU重传结果一致。未到达/未执行协作等待如实报告；有来源且能合法补齐的平台依赖同单元继续。
4. 业务末端冻结后，独立声明原403730补充析构当前雾层，核对原字节记账/指针/零引用及正常助手退出；父字形/容器/CRT清理照旧验证。新补充清理不算业务前向进展。
5. 独立复核完整父来源和新增资源根/循环，不把已清理快照恢复成当前来源；针对创建根、尺寸、原生ABI/指针/像素/padding/自然栈/停止理由与完整状态做破坏测试。六分支来源与证明独立绑定；验证器进程分组和原生构建路径按PID隔离。

## Risks / Trade-offs

- 当前逻辑设备与新自有GPU域并存 → 接口边界作显式类型投影，不传失效原生句柄或修改原IAT。
- 后继首次触及未保存对象/其他资源 → 运行到精确真实依赖并保存修复前提，不能注入返回值或人为提前停点。
- 六分支全父链成本 → 复用只读来源缓存并以最多三个独立工作进程分组，不将不同进程拼作一个原生寿命。
