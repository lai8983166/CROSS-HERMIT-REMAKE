# Proposal

## Why

The independent April week 4 school example can grow students and confirm career/relationship fields, but has no MVP completion or sourced destination for the resulting ADV request. The next step must complete those result fields without treating a loaded chapter as completed or advancing the calendar early.

## What Changes

- Execute the native course result task with actual MVP script dispatch and completion, declared presentation readiness and bounded waits.
- Derive the MVP from frozen settled class order and staged totals, update its capped count once, and expose the sourced CH003/Chapter016 handoff.
- Add an owned session command and visible result completion action with duplicate, invalid input and restart protection.
- Preserve all previous evidence and the independent example boundary; Chapter016/017 body playback and week advancement remain future work.

## Capabilities

### New Capabilities

- `school/course-result-handoff`: MVP recipient/count and ADV entry handoff after supported course settlement and confirmation.

### Modified Capabilities

None. The main spec inventory does not yet contain school capabilities.

## Impact

New source emulation/evidence and pure Godot result module; school session, course panel, tests and audit documentation. No original save writes, runtime dependencies or remote publication.
