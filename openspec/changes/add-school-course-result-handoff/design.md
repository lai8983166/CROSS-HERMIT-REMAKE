# Design

## Context

See proposal.md. Settlement owns staged totals and a frozen school snapshot; confirmation owns relation/career fields. Native 4C1AA0 calls 4BD870 once, runs 4BDAC0/MVP, confirms, increments package+0x120 and loads CH003 with next task7 before requesting6. CH003 selects Chapter016 at4/4, whose body chains to Chapter017.

## Goals / Non-Goals

Execute the real result task and MVP VM in one isolated CPU with bounded declared UI readiness. The separate CH003 execution stops at the genuine Chapter016 resource entry. No chapter-body END, calendar mutation, original save or inferred earlier school chronology.

## Decisions

- Reuse course initialization/planning/growth emulator, enable only explicit native VM/task ranges, supply exact allowlisted local YBC bytes and finite write regions. Fake MVP return values would conceal input waits and are excluded.
- Keep native evidence/compact fixtures separate from source-only runtime rules; preserve old frozen reports. Pure Godot selects from frozen class order/staged totals and derives the count/handoff without accepting externally computed outputs.
- Add a revision-checked completion command after confirmation. It reads owned growth, settled class order and initial counts; plan edits cannot change the winner. Publish one atomic revision and ordered journal steps, with deep copies and once-only replay.
- Present result details in a separate compact result area or page if the existing course page cannot fit at1024x768. Date and pending story status must be visible.

## Risks / Trade-offs

- Simulated presentation readiness → label isolated source evidence and retain blocked input/button cases.
- Negative recipient native indexing → reject missing positive winner in the port rather than manufacture an award.
- Loaded chapter mistaken for completed story → record entry boundary and pending task7; no weekly transaction.

## Migration Plan

Additive modules and independent example fields; no save migration. Verify and commit each of the three stages locally without push.
