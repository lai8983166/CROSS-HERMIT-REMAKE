# Design

## Context

参见proposal。沿用WorkMachine新战斗/任务工作布局，不装载任何战后快照，也不复用旧渲染助手句柄。学校工具的输入复位/覆盖层机器码边界可复用；旧绘制关闭门和模拟平台返回不继承。

## Goals / Non-Goals

**Goals:** 每例原终局请求后两次任务自然返回，原输入复位每次实际运行；第三次任务在原栈进入VM、执行167、构造原覆盖层包到首次资源查询。

**Non-Goals:** 不返回假的资源或绘制结果；不宣称第三任务返回、117自然到达、画面输出或任务退出/奖励完成。

## Decisions

- 新增有界输入/owner方法初态和零SEH头拥有页；7A4A00/7A49FC在首根前指向声明owner。只读取覆盖层原点，不填资源缓存或设备，不执行未初始化的资源查询。
- 每帧以明确根运行425DE0复位，再454CF0/453F10/46B470/432100；第三425DE0后454CF0沿原栈运行至407870入口，入口第一条不执行。原输入的630为待处理IME请求标志，不能误称索引或由宿主清除。
- lstrlenA及ImmGetOpenStatus(null)首次/重放均实际调用Windows函数；保留原IAT目标和真实参数，前驱GetTickCount精确重放仍用采集值。
- 守卫与根ABI仅私有扩展同算法；全部拥有区/57项CPU/原摘要与pending原栈新实例复现，独立核对输入复位、任务阶段、VM单条167、覆盖层包和SEH头。
- 固定前驱验收SHA及29项清单产物，递归保护原资料；停点不称原清理，虚拟对象原样保留，实际TLS资源单独正常结束。

## Risks / Trade-offs

- [原任务首次读未初始化owner资源] → 精确停止于首次查询入口，保留依赖，不伪造缓存或关闭绘制门。
- [部分调用被当作返回] → 完整根与第三pending根分别记录；检查原返回地址/栈/CPU和实际未执行入口。
- [空IME/字符串被当成系统输入集成] → 明确只有实际null查询/空缓冲方法，未采集键鼠或运行原外层线程。
