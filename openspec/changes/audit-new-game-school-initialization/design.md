# Design

## Context

See proposal.md. Native49E930 clears a bounded state region, resets roster/groups, copies original relationships and calls4D3E90 for101/3/4/9. It assumes student records were loaded earlier; that predecessor is not yet executed. Old group rules cover only117/118 and returned campaigns have zero teachers.

## Goals / Non-Goals

**Goals:** Execute the complete initialization function and dependencies with source-backed template inputs; reproduce the school field subset, teacher profile ownership and prepare phases in an independent session.

**Non-Goals:** Preceding asset/template loader, whole new-game/ADV/menu chronology, current returned campaign migration, member drag UI and original saves.

## Decisions

- Extend the existing audit emulator in a new tool without rewriting old evidence. Load original student templates explicitly, record the exact bounded memset boundary, and allow only state-region/member-record and preparation control writes.
- Freeze pristine, dirty-state and repeated initialization plus actual date unlock/reconcile/rate checkpoints. Source rules include verified call arguments, template profile fields and original directed relationship bytes; expected snapshots never become runtime inputs.
- Preserve native zero-filled raw roster tails separately. Normalize only inactive canonical catalog slots to−1 for existing pure group helpers, retaining raw rosters so the mapping is reviewable.
- Add a source initializer constructor and a standalone school session. The session owns immutable profiles and course data; preparation precomputes all phases before a single publication. Revision/journal and duplicate behavior are tested. No initializer is applied to an existing returned campaign.
- Extend the group helper with a distinct initializer101 rule binding. Legacy Chapter012117/118 rules keep their original domain, registration context and validation. The initializer scope permits only101; no fabricated later teacher joins.

## Risks / Trade-offs

- [Template load predecessor remains declared] → Bind each template to the original image and state the complete-function versus complete-game boundary.
- [Native raw counts/derived fields can be temporarily stale] → Separate initialized, unlocked, reconciled and rated snapshots.
- [Generalizing teacher domain changes old refusals] → Explicit rule domains and legacy regression tests; current campaign/UI remain byte-identical.
- [Large initializer write trace] → Keep deterministic count/hash and merged touched ranges plus bounded memory hashes, while checking every write during execution.
