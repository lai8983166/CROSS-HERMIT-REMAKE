# Design

## Context

参见proposal动机。父寻路工具已执行原地图与路径包函数，新增私有执行器复用其逻辑布局，不修改冻结源。原AI调用分为路径段领取、格中心选择、速度/朝向计算、定点位置更新及到位/占用检查；反编译返回签名不可靠，以原机器码为准。

## Goals / Non-Goals

Goals：连贯执行声明路径段中的原函数，自然写入单位坐标；独立规则验证状态、停止/受阻分支及定点增量。动画资源关闭作为明确初始输入，执行原动画函数的真实关闭分支，不返回代用结果。需要的数学/CRT原指令同样执行，未知边界拒绝。

Non-Goals：不要求窗口/解锁，不宣称完整AI选敌、实机关卡、全动画资源或场景线程连接，不以审计驱动的多次函数根代替整个世界帧。

## Decisions

- 新独立Unicorn运行器使用原映像及严格代码/写入域；完整保存新拥有区，原地图只读。原路径包直接由原寻路结果进入单位工作区，领取和位置推进由原代码执行。
- 用纯坐标/定点/浮点规则模型预测输出，并在新实例完整重跑核对全内存及指令/写入轨迹。模型与原执行对照不合时检查CRT常量、float存储舍入和签名，不能替换游戏函数结果来通过。
- 结构化案例覆盖方向、段到位/耗尽、速度/地形比例、缩放状态和阻挡；不支持的资源/AI分支明确保留。
- 冻结父验收除总spec/.gitattributes外的27份文件，并递归核对原资产/存档/检查点；保留失败日志，新证据不覆盖旧路径。

## Risks / Trade-offs

- 原CRT数学环境存在隐含全局依赖 → 先执行小型ABI/数学对照，再扩展连贯语料，缺失环境必须明示来源。
- 声明关闭动画门只能证明移动规则 → 所有产物固定隔离作用域，完整动画/场景连接不据此完成。
- 原整数/SHORT/float截断不同于高层运算 → 明确逐步32位浮点与16位字段转换，记录数值边界。
