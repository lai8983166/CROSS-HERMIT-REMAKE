# Proposal

## Why

原场景4条件VM与选择已验，但以战后完整快照和声明时间为入口。R4到R5还缺同一实例从初始交战、原计时到事件选择的连续数据连接。

## What Changes

- 首根前一次声明战斗/地图/已加载脚本与一致任务布局；随后完整原世界46B470和完整432100事件按明确有界顺序推进，不恢复或加载战后快照。
- 打开原108B3A门，执行原计时及门后交互/提示体，不写派生时间、HP、死亡计数或选择。
- 覆盖职业1/3敌我致死、阈值保命、中性及短时限七例，连续到首次原终局请求或对照预算，随后显式原473860整理。
- 独立核对逐帧时间、交战HP/随机流/记账、逐次事件条件与选择、实际结果数据，并进行全拥有内存/CPU/原轨迹新实例重放与保全验收。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

无。落实reverse-engineering/completion现有R4/R5要求，属于隔离研究工具和证据，skip_specs为true。

## Impact

新增有限研究工具、专项和证据，不修改冻结工具、原代码/IAT、存档/检查点或Godot。外层原生线程、加载器、真实输入/显示、终局展示脚本推进/任务退出与奖励另计；不把明确世界/事件根循环称原4539B0完整调度。
