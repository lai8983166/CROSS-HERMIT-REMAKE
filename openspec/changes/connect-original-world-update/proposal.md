# Proposal

## Why

原基础近战已接到完整单位更新和死亡战场移除，但单位根的手工顺序没有验证原世界外层的250槽扫描、前后全局处理及每帧重置。需要把同一有效实验寿命中的战斗状态接入完整46B470返回路径。

## What Changes

- 在新实例的已验绑定/攻击/命中/HP前缀之后、补充清理与TLS释放之前执行完整原世界更新根，覆盖四职业、非致命/受击/HP0及总门关闭对照。
- 连续有限帧验证250槽扫描和实际单位实参顺序、区域统计/工作列表/全局状态的原帧前后处理与重置，不由宿主替原体调度单位或清字段。
- 独立全状态模型、原调用/实际写入与57项CPU/全拥有区新实例重放，专项与回归、父47份冻结/递归保全后更新总spec并本地提交归档。
