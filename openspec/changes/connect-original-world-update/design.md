# Design

## Context

参见proposal。父受击/死亡执行器保留当前自有TLS和原HP后的双单位/动画/效果状态，但手选完整单位根尚不能证明外层世界更新。

## Goals / Non-Goals

目标是声明的基础近战/空交互环境中完整46B470的有限连续帧与总门关闭对照，含250槽扫描、全局前后处理和原每帧状态重置。没有原窗口/线程/输入/加载器寿命重建，不以本单元称整个战斗/全部规则/胜败奖励完成。

## Decisions

- 私有继承冻结父工具，沿用新实例的原绑定/出手/效果/HP前缀，在补充清理前改用完整世界根；不使用旧已清理检查点，也不插入独立单位根。
- 正常门、pending=-1哨兵、空列表/交互/事件和世界所需对象字段在首根前声明，注明来源与用途。所有后继门控/单位顺序/清表/计数由原体完成，禁止原函数结果代用或主机派生字段回写。
- 独立模型显式处理原帧前、单位扫描和帧后状态；核对全部250单位槽/缓存列表及相关字段，不把只比较两单位当全世界状态。
- 全拥有区和57项CPU/实际指令写入轨迹新实例重放；原CRT/数学体及真实TLS/LastError叶继续执行，每实例正常清理。
- 保留依赖探针失败和正式新路径证据；父47份冻结/递归保全、专项和相关回归通过后同步总spec、本地提交归档。

## Risks / Trade-offs

- 外层包含输入/脚本/资源依赖 → 保留其原检查并清楚声明当前环境；未知路径拒绝，不从返回桩跳过。
- 原列表与每帧重置可推翻独立单位实验的累计值 → 以原完整帧实际字节为准，模型另解释前后阶段。
- 250槽扫描/全拥有区使报告较大 → 使用固定gzip和有限帧预算，仍保留全部状态与实际轨迹摘要，不用抽样代替。
