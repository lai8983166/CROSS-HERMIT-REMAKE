## Context

图集=素材库已定性（缝分析）；BIN 三层值域小（terrain 0..12, variant 小整数, object 0/2/4/11/12/...）
且 2/3 为零。MAP01.MAP 头部有 255×4B 索引表（8..0x404）与 53 对步长表（0x404..0x4D4）。
回退 BMP（172×128）是世界布局的宏观弱参照（相关度对微观错位不敏感，但对宏观结构可辨）。

## Goals / Non-Goals

**Goals:**
- 层值→贴片映射：优先从数据结构推出，推不出则收敛假设并标注
- 合成图达到"宏观布局可辨"（回退 BMP 相关 + 用户肉眼），叠加态逐格对齐
- 三层语义写进 formats.md（定案或开口）

**Non-Goals:**
- 不做地形高度/立体（D3D 起伏后续）
- 不批量 50 张（工具参数化即可，只产 MAP01）
- 不追求贴片 100% 与原作一致（动画帧、物件层叠细节留开口）

## Decisions

1. **贴片几何从图集实测反推而非预设**：先在图集里探测"贴片栅格"——32×16 菱形在 256×256 页内
   必然留下周期性边缘（相邻贴片色差沿菱形边），用边缘响应自相关找出贴片尺寸/相位；比猜
   "32×16"更稳（可能是 64×32 或交错半格）。
2. **映射假设族 + BMP 相关度评分**：并行实现 3~4 个候选映射
   （a: terrain 值=贴片行；b: 索引表 255 项=层值→UV 表；c: 步长表 53 对=行锚定；d: 简单
   行列平铺），各自合成后与回退 BMP 算相关度取最高，且需超"素材平铺基线"才有意义；
   平手则人工目检裁决。
3. **合成离线、加载即用**：compose_map.py 产 PNG，运行时零解析（延续 atlas 管线）；菱形交错
   排布用 PIL 逐格 paste（6144 次，秒级）。
4. **对齐免费获得**：合成图的世界包围盒与数据层同构（同一 cell_to_world 排布贴片）→ 叠加态
   不需要拉伸适配，main.gd 直接按 world bbox 贴。
5. **三层语义只写有据结论**：映射验证过程中能确认的（如 terrain 与贴片行的相关性）写定案；
   object 层（条纹）在合成中的角色存疑就标注，不硬塞。
6. **索引表/步长表分析先行**：任何映射假设前，先做两表的结构画像（值域/单调性/与页边界的
   数值关系），分析结论进 design 修订——避免在错误表语义上浪费渲染迭代。

## Risks / Trade-offs

- [映射全部不达标（BMP 相关不超基线）] → 收敛为"部分合成 + 明确开口（需实机截图）"，spec 的
  宏观可辨场景若不满足则 change 以部分交付收尾并明示——不假装达标
- [BMP 弱参照误导] → 相关度只作筛选，最终以用户肉眼裁决；两证据冲突时记录分歧
- [贴片自相关探测失败（无清晰栅格）] → 回退预设 32×16 假设族，风险已知

## Migration Plan

新增 compose 工具 + composed 资产；main.gd 贴图态换源。回滚 = 还原 main.gd、删新资产。
