# Design

## Context

参见proposal。父敌方交战模型固定相邻目标，进入阶段12以前的射程检查直接跳转20，已验移动工具使用空动画资源。需要私有桥接实际动画及世界单位顺序。

## Goals / Non-Goals

从原绑定、待机超时和自主选敌开始，追击射程外的被动玩家，首次进入射程后两次完整攻击及自然再决策。目标保持静止，初始资源/地图/空输入为声明；双方自动交战、复杂动态阻塞路线、其他技能/AI与加载/显示/结算继续按总规格保留。

## Decisions

- 私有继承已验敌方机器/原观察器，首根前迁移目标坐标及一致的占用/历史格字段；模型自行构造同样输入。初始化后禁止宿主坐标/目标/技能/计时或状态写回，世界是唯一游戏驱动根。
- 扩展独立移动模型的地图占用、原角度/float32/定点位移、路径包和完整移动动画事件；保留世界每帧列表、统计、原HP和随机顺序。以原调用者证明寻路/移动嵌套在攻击/世界内部。
- 按受影响范围核对路径控制器/池拥有字节、实际坐标store PC及占用跨格；来源范围保持原指令准入，37拥有区/57CPU/全部指令写轨迹新实例复现，不把输出作为独立模型输入。
- 四种近战职业和代表性斜向路径、关闭搜索对照；有界最多384帧，正例两轮及额外再决策帧，负例96帧。保留全部250槽和无损分页。
- 冻结最新父35份和递归资料，专项/相关回归/严格规格通过后更新总spec、提交归档。任务最后只准备验收材料，归档/最终Git封存为随后完成动作，避免自引用勾选。

## Risks / Trade-offs

- 原移动动画改变完成位/方向和事件时机 → 复用真实动作表并逐字节核对；不把旧空动画试验直接当完整流程。
- 目标占用影响局部路径准入 → 原占用和候选列表同时核对，任何未支持依赖拒绝而非代用返回。
- 路径池比既有近战发生更多写入 → 分别记录拥有区字节和生命周期，完整新实例重放；独立覆盖范围在文档如实列出。
