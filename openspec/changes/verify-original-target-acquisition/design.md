# Design

## Context

参见proposal动机。普通选敌47A920位于47A8E0返回的unit+2ACh AI工作区，扫描计时+28h/间隔+0Ch。阵营来自记录+A4与CTRL+115AACh矩阵，候选列表位于CTRL+DC8ECh。原视野33段在MAPCOM首容器，尺寸表位于59558C。

## Goals / Non-Goals

Goals：解释普通敌方选择、原十策略、扫描节奏、过滤与同分次序，从完整475700移动分派到待执行攻击/目标行动，再执行明确补充原4751F0消费根。

Non-Goals：治疗优先、反击/特殊AI、随机技能替换、完整477980攻击处理/命中/伤害、活动动画/原生世界寿命。关闭分支必须由声明初态使原代码实际判断，不给结果桩。

## Decisions

- 私有继承MAP05执行器，增加控制器尾部矩阵拥有区及只读完整MAPCOM，按原容器偏移声明33个掩码指针。候选单位/记录及阵营矩阵为声明输入，其他候选只读；原职业/技能静态表保持RX。
- 使用原正常职业基础技能，声明source unit+2A7启用自主判断、4FA/4FC为−1，无特殊技能配置/治疗工作；普通选敌及47C580基础技能路径由原代码自然执行。未知依赖即拒绝。
- 独立模型覆盖阵营映射、死亡/禁选状态、据点/特定记录排除、范围掩码、unsigned与signed比较和定点像素L1距离。严格比较使同分保留列表前者，不擅自替换为最近格或HP比例。
- 完整475700根逐步执行移动命令初始化、扫描与请求生成；无目标语料继续原476680(unit,1)，区分命令阶段293与移动阶段294。发现非零待执行命令后停止该业务根，再明确执行原4751F0，消费请求而不伪称完整世界下一帧或攻击体执行。
- 独立预测完整520h单位与所有readonly候选、实际内存/CPU/指令写入轨迹。父29份冻结及递归资料保全；修改仅新工具/证据与总spec/.gitattributes。

## Risks / Trade-offs

- 反编译漏返回、部分十策略体为空 → 按机器码读出实际signedness、字段与EAX，保留重复策略。
- 移动AI混用阶段字节 → 以原调用参数1和完整单位比较核对，无宿主推进阶段。
- 活动动画清理可能扩大范围 → 声明空动画链，实际执行原清理函数；如遇未知资源拒绝，不替代原函数返回。
