# Proposal

## Why

已验主/局部移动尚未连接普通选敌和攻击请求。需要从原命令分派自然选取目标，解释扫描节奏、阵营/状态/视野过滤、十种优先级及目标/技能填写和命令交接。

## What Changes

- 使用原MAPCOM视野掩码和原职业/技能表，在声明候选单位与阵营矩阵上执行原47A920/47A9D0/47AED0普通选敌，独立核对过滤、十种策略、相同优先级顺序及扫描计时。
- 完整475700→476DD0在移动命令中自然生成目标/技能/位置和待执行命令；以明确补充的原4751F0根消费请求，验证交接，不进入后续攻击伤害体。
- 同一原地图/对象寿命下核对无目标时继续局部移动，完整单位/内存/CPU/轨迹独立重放；专项/回归与父29份冻结、递归原资料保全后更新总spec，提交并归档。
