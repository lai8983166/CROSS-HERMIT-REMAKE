# Proposal

## Why

- 从已验六个保留任务分支连续执行opcode30前缀至原CreateFontA入口，独立核对完整状态、真实参数/栈和首个未执行资源边界，不重置VM或替代游戏函数。
- 来源/变异/集成回归、全链保全和严格规格，更新总规格实际边界，归档并本地提交。
