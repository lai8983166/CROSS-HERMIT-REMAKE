# Proposal

## Why

已验双方近战在存活状态停止，尚未说明自主交战自然致死后的敌我差异、移除及实际结算输入。R4需要将同一世界寿命推进过这些边界，为R5提供真实来源。

## What Changes

- 两种近战动画家族（职业1/3）各覆盖敌方死亡与玩家死亡；双方实际出手后以自然伤害致死，原死亡命令/统计/动画/移除/后继帧全部由世界更新驱动。
- 设保命阈值及不敌对对照；仅首根前声明HP/回复间隔/反应字段，运行中不注入攻击、死亡、HP或停止结果。
- 自然交战结束后明确调用一次原473860结算输入根，核对实际产生的击杀/贡献/死亡记录、分数与原4307B0敌对存活条件；不把此独立根称为原任务自动胜败转换。
- 完成独立函数契约、所有原拥有字节/CPU/轨迹新实例重放、相关回归、历史保全及总路线图更新归档。
