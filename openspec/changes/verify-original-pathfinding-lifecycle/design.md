# Design

## Context

沿用固定SHA脱壳映像588b4288…，反编译仅作索引，指令及原常量表为准。参见proposal.md动机。锁屏守卫已只读确认locked_foreground，本单元不要求解锁。

## Goals / Non-Goals

Goals：在独立Unicorn实例执行搜索、直线/方向路径、压缩、逐点消费和原工作表清理；覆盖有障碍、占用、同起终点、模式差异及边界。模型独立推导结果，执行器记录指令/写入摘要和完整拥有区前后字节，验证只读输入保全。

Non-Goals：本单元声明地图/链表池输入，不从不存在的原生构造结果恢复，也不称完整AI、单位实际坐标更新、原MAIN线程连接或Godot实现。1001扩展上限等未实际覆盖分支须明确报告。

## Decisions

- 仅允许已声明原函数范围，未知调用/断言/越界写入直接失败。原游戏寻路、地图查询、链表、memset和栈检查实际执行，无游戏函数返回桩。
- 初始地图、地形分类与模式、占用、空表/预分配节点是明确的隔离输入；记录完整字节及布局和独立校验，避免依赖旧失效句柄或缺失堆。
- 先以小例核对ABI/原返回和队列布局，再覆盖结构化及确定性地图语料。独立纯模型核对路径/搜索顺序与返回；新实例完整重放核对全状态/轨迹，二者分别报告。
- 输出只用新路径；父验收冻结59份文件及其递归资源/存档/检查点保全。总spec与.gitattributes可追加本单元事实/格式。

## Risks / Trade-offs

- 反编译遗漏返回值/this偏移 → 逐处检查机器指令与自然栈/ESP。
- 原算法不是标准最短路径保证 → 忠实记录平方启发、同分排序、障碍高代价和压缩规则，不用标准A*输出替代。
- 隔离输入无法证明原场景实际移动 → 作用域标记固定，R3/R4/R6不据此完成。
