## MODIFIED Requirements

### Requirement: DxAnim 容器解码
导出工具 MUST 校验并解析 DxAnim 容器 `{u32 总长; u32 块数; u32 offs[]}`：
`offs[0]==8+4n`、偏移非递减、头部总长等于文件长度；校验失败 MUST 报错退出且不得产出
半成品。动画程序中的 10B 指令 MUST 按低两位 opcode、终止/循环标志和四个打包的 12 位
描述符引用解释；可见层 MUST 经描述符表解析为最终 BMP 帧、局部偏移、绘制属性和引擎时长，
不得再把指令中的有符号短整数直接当作 BMP 帧号。一个逻辑时刻包含的多个描述符 MUST 保持
为并行图层；生成子动画的指令 MUST 保持父子并发和累积偏移，不得串行展平。

块5画布矩形、块6 8bpp BMP 和块7换色板 MUST 继续按原始档案导出；不存在、越界或无法
终止的程序引用 MUST 产生明确验证错误或显式回退，不得靠邻近帧、连续帧或亮度猜测修补。

#### Scenario: 容器自洽校验
- **WHEN** 解析任一单位档 DxAnim 文件
- **THEN** 任一结构校验失败即报错退出，不产出半成品

#### Scenario: 描述符解析
- **WHEN** 动画指令的一个逻辑时刻引用一至四个有效描述符
- **THEN** 导出结果包含每层的最终 BMP 帧、偏移、绘制顺序/属性及由引擎描述符确定的时长

#### Scenario: 复合动画并发
- **WHEN** 动画程序生成带局部偏移的子动画
- **THEN** 同一时间轴输出父动画与所有存活子动画的并行图层，而不是先后拼接两段帧序列

#### Scenario: 帧解码
- **WHEN** 导出一档
- **THEN** 每帧 PNG 尺寸与帧头一致、索引0透明，并使用帧内嵌调色板直出

### Requirement: 精灵资产产出
每个被导出的档 MUST 产出 `assets/unit/<档>/frame_*.png`、`_preview.png` 和
`prototype/data/unit_sprites.json`。汇总表 MUST 保存帧路径、画布/锚点、渲染就绪的动画
时间轴、每个逻辑时刻的图层列表、循环点、引擎时长与方向镜像标志。单图层旧格式记录 MAY
作为兼容输入继续读取，但新导出结果 MUST 使用能无损表达多图层的 schema。

MOVE 映射 MUST 来自原版移动动作和方向映射数据：八向均选择原版指定动画，并把表项低两位
解释为水平/垂直镜像标志；不得通过动画号偏移、块切换或最长连续帧启发式推导移动序列。
配置仍 MUST 可在 JSON 中覆盖，以保留 Mod 替换能力。

#### Scenario: 八向移动序列完整
- **WHEN** 导出 A0A、B1A 或其他包含原版移动动作的单位档
- **THEN** 八个罗盘方向均解析到有效时间轴，镜像方向复用正确源动画且仅应用引擎镜像标志

#### Scenario: 黄金帧链
- **WHEN** 解码已记录黄金样例的 A0A/B1A 移动指令
- **THEN** 最终 BMP 帧号、图层偏移和时长与原版描述符链的期望值逐项一致

#### Scenario: 帧序列完整
- **WHEN** 导出一档
- **THEN** 帧文件数与容器帧数一致，默认 MOVE/IDLE 序列的帧引用全部在界内

#### Scenario: 资产可替换
- **WHEN** 修改 JSON 中的方向映射、时间轴、图层偏移、锚点或时长后重载
- **THEN** 渲染按新数据工作，视图代码不依赖某个单位档的硬编码动画号

### Requirement: sim 精灵渲染
战斗视图中配有 `anim_id` 的单位 MUST 按状态与八向朝向选择数据表时间轴，绘制当前逻辑
时刻的全部图层，并应用每层偏移、绘制顺序及水平/垂直镜像。动画时钟 MUST 由确定性的 sim
帧推进，并在动作或方向键变化时从该时间轴起点重新开始；不得使用全局单位序号错相代替动作
生命周期。位置仍随格间移动平滑插值，换色、脚底阴影和缺失资产色块回退行为保持不变。

#### Scenario: 精确移动播放
- **WHEN** 单位开始移动或移动方向发生变化
- **THEN** 对应方向的原版行走时间轴从起点播放，全部图层与单位位置同步推进

#### Scenario: 精灵渲染
- **WHEN** 单位在移动
- **THEN** 显示行走帧序列循环，位置随格平滑插值

#### Scenario: 镜像方向
- **WHEN** 当前方向表项包含水平或垂直镜像位
- **THEN** 视图镜像图像和局部偏移，且不改选到另一容器块或另一动画

#### Scenario: 回退
- **WHEN** 单位资产、时间轴、图层帧或 `anim_id` 无效
- **THEN** 自动回退色块渲染、记录可定位的验证信息，战斗逻辑不受影响
