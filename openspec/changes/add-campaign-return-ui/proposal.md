# Proposal

## Why

战斗返回学校的规定输入域已通过完整回归，但主窗口不能查看或操作这条返回流程。需要把现有数据链呈现在原型中，方便直接检查战果、一次性确认和学校名单。

## What Changes

- 新增独立的返回流程演示入口，保留默认战斗原型。
- 使用实际本地三学生战斗终局与明确选择的场景5源样例，呈现战果、确认结算、学校名单及学生详情。
- 页面只读取共享目录计算结果；重复确认或切页不重复奖励/周结算，重开演示创建全新会话。
- 演示持续说明战果来源与未完成排课边界；不把本地胜负派生成原版事件或写入原版存档。

## Capabilities

### New Capabilities

- `game-flow/campaign-return-ui`: 有来源的战后返回演示、战果确认和学校数据浏览。

### Modified Capabilities

无。既有地图、战斗默认操作和返回事务语义不变；尚未归档的返回变更保留独立验收记录。

## Impact

Godot主场景、新增演示会话适配器与Control界面、对应回归和入口文档。复用现有返回事务和冻结来源文件，不修改原版报告，不引入网络、外部依赖或原版游戏操作。
