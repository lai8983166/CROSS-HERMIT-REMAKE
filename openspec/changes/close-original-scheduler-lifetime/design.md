# Design

## Context

R1有独占Job的真实原版完整初始化/正常关闭观察器。R3保留检查点的MAIN+64h调度管理器为空；原421850通过56E050创建421F50工作线程，虚调用任务，按真实事件/临界区同步后收尾。单靠宿主解释器替代线程会失去原CRT/同步寿命来源。

## Goals / Non-Goals

Goals：原完整运行时内验证独立调度对象从构造/清空/注册、原CRT线程/原回调、事件唤醒、节点移除到析构的闭环；独立模型校验完整对象字节和多节点顺序。

Non-goals：不把原基类422330空回调说成战斗/VM执行，不把独立对象说成旧检查点原地继续；不接入保留场景世界、物理输入或49E540整帧。

## Decisions

- 复用R1原版启动/关闭实现的私有函数globals副本，在其已检查Job、HWND、属性归属之后及正常WM_CLOSE之前运行实验；冻结历史源文件不改。新结果明确增加“私有进程缓冲写入”，不冒充原观察器全程只读。
- 仅VirtualAllocEx的新私有数据/代码缓冲可写。通用x86调用桥传ECX、0–3个stdcall/thiscall参数，记录返回值和调用前后ESP，单次远程入口线程退出后才复用缓冲。桥从RW写入后转RX并刷新指令缓存；原游戏代码/IAT不改且前后完整核对。
- 原421540/421660、422290、4216C0、4217C0、4215F0等直接在自有原版中执行。真实原_beginthreadex/421F50/基类虚回调均由原代码驱动，不手工伪造线程或SetEvent结果。原基类回调422330返回，适于闭合完成/退出/移除路径。
- 使用零/脏对象缓冲、多个桶/同桶链、原422560禁用后4225A0恢复验证；输入是明确独立探针状态。原代码若留下线程句柄，则额外关闭明确记为实验所有者补充清理，不谎称析构已关闭。
- 原运行时超时/错误保留实际失败与强制关闭标志，不把进程杀死写成正常退出；前后存档和旧证据校验保持。

## Risks / Trade-offs

- 远程调用依赖原CRT已初始化 → 仅在原WinMain主循环且所有原初始化对象存在后运行；先比对原函数及IAT身份，限制原入口白名单。
- 线程完成时序 → 等待实际线程、读取实际状态；不以休眠时间推测完成，完整记录等待/退出/关闭结果。
- 空任务与场景进度混同 → 报告和总spec保留R3未完成，下一步恢复场景任务注册与4539B0世界入口。
