## Context

DxAnim 解释器已能正确还原单位档和 `##E` 档的多图层时间线。原版 `UnitAnim.cpp` 的动作选择路径使用动作号与八方向表选择 block 0 动画；移动为 action 3，普通攻击为 action 5。

逆向样例：action 5 的 N/NE/E/SE/S/SW/W/NW 分别对应动画 21/22/23/24/25/24/23/22，东向与东侧对角使用水平镜像。A0A 时间线为 36 tick，B1A 为 48 tick，挥砍层已经嵌入单位动作。职业 1/3 的默认攻击 101/103 在技能明细表中使用 action 5，且 projectile、impact 与 hit-effect 字段均为 0。

## Goals / Non-Goals

**Goals:**

- 让当前普通攻击按原版 action 5 播放正确方向、复合图层和持续时间。
- 每次攻击重新起播，非循环时间线结束后回到待机画面。
- 只为具有原版非零效果标识且已经配置映射的攻击播放外置 `##E`。
- 保持战斗判定、确定性和缺失资源回退行为不变。

**Non-Goals:**

- 本变更不猜测尚未语义标注的全部技能与 `##E` 档案对应关系。
- 不实现受击、击退、死亡的完整动作表。
- 不修改伤害公式或攻击节奏。

## Decisions

1. **动作映射复用原版方向表。** 在共享解码库中增加 action 5 映射，导出为 `attack_by_dir`。不通过帧图启发式猜动作，避免不同单位档帧号差异导致错配。

2. **攻击起始帧属于战斗单位状态。** `_attack()` 写入 `attack_started_frame` 并把朝向更新为目标方向。视图以该帧作为攻击时间线时钟，因此连续两次同方向攻击也会从首帧重新播放。

3. **非循环攻击播完回退待机。** 攻击时间线使用 `repeat_without_loop=false`；取不到当前攻击帧时解析并绘制待机时间线，而不是重复 action 5 或依赖全局动画时钟。

4. **效果 ID 与视觉资源映射分离。** 战斗事件携带 `attack_id` 和 `effect_id`。视图先检查显式职业覆盖，否则只按非零 `effect_id` 查 `attack_effects.json.effect_ids`；没有映射就跳过。删除全局默认斩击语义，但保留已导出的命名效果供后续映射。

5. **普通攻击的挥砍由单位时间线负责。** 不从单位动作拆出武器/残影图层，也不额外叠加 `01E#21`，从而保持原版层顺序与锚点。

## Risks / Trade-offs

- [尚未标注全部效果 ID] → 未知非零效果暂不播放，后续以逆向证据逐项补充映射，禁止猜测默认值。
- [战斗状态仍可能保持 ATTACK] → 视图在攻击时间线结束后明确回退 IDLE；不把素材时长耦合进确定性战斗逻辑。
- [不同单位档 action 5 长度不同] → 运行时读取各自时间线总长，不使用统一硬编码秒数。

## Migration Plan

1. 重新导出单位帧表，生成 `attack_by_dir`。
2. 扩充战斗单位与攻击事件字段。
3. 更新运行时动作选择及外置效果过滤。
4. 更新测试并执行全量回归。
5. 启动窗口进行用户目检；失败时保留旧导出资源可通过 Git 回滚。
