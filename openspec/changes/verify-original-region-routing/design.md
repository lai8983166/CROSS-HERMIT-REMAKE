# Design

## Context

参见proposal动机。原MAP05逻辑地图64×96，VPT含四段区域记录和四张signed SHORT格索引；模式0/1/3各120区域，模式2有96区域。CTRL+2A55C为抽象对象、通用搜索器偏移10h；CTRL+2A634为细格对象、通用器偏移18h，两者需要独立池/索引。原44F1E0使用7A3FA4全局短暂压缩缓冲。

## Goals / Non-Goals

Goals：以原文件内容接通区域索引/重定位/搜索/压缩及完整AI主路径；独立解析图和原地形规则，比较所有包/单位状态、工作池和当前全局缓冲。

Non-Goals：不重做文件API/原分配器构造和R3外层寿命，不把完整寻路等同攻击/世界帧。实际地图与地形为原字节，单位/占用/池/CPU根为声明实验输入；不引入游戏返回桩。

## Decisions

- 原文件按固定SHA读取，独立严格解析尺寸、记录、边/权及格索引；原44E5D0负责将四段相对记录偏移转换为当前地址，宿主只提供原始字节和段指针，不替原代码写重定位结果。
- 独立当前内存布局适配6144格；复用已验源移动CPU/调用约定与规则，隔离粗/细搜索池和readonly地图。7A3FA4至其200字节缓冲跨两个数据页，仅该缓冲可写，不改原代码/IAT或整页清零。
- 原44EA80同区返回2，由完整47D210选择细格回退；异区按原边权、平方启发、同分前插、开放更新/关闭重开处理。原44F1E0压缩依赖实际地图直线可通性，按其反向链和扫描规则单独建模，不能套用其他压缩算法。
- 单独查询覆盖四模式与同区/异区/避让，完整AI案例以模式0、无动态占用和关闭动画资源门从阶段0自然推进。原始失败/预算记录保留，遇未知函数或非法写入立即拒绝。
- 冻结父31份清单除总spec/.gitattributes外29份，递归保全历史；每项工作交付测试及说明，集成验收完成后本地提交/归档。

## Risks / Trade-offs

- 反编译漏返回/this偏移 → 以源机器码、ret/ESP和每根寄存器为准。
- 全局压缩缓冲容易误改原源图 → 仅数据页设置写权限、逐次限制精确缓冲地址，全页快照与新实例重放。
- 启发不保证最短路、源压缩可能保留多余点 → 忠实对照原输出，不以标准A*或最短路代替源规则。
