# Design

## Context

参见proposal。前驱六例已验完整世界与38拥有区；终局函数由声明TASK选择0出发。场景4原433720依次判断敌对存活、经过时间、己方伤亡与全灭，经454AB0/454AF0调用原条件VM并设置选择。

## Goals / Non-Goals

**Goals:** 四类实际战斗输出×正常/到时时间；完整原432100、条件VM及结果整理，独立规则与全状态/CPU/轨迹实际重放。

**Non-Goals:** 不将完整内存作为新根输入等同原CPU恢复、原场景加载或外层并行事件同寿命。终局展示脚本/任务退出、奖励发放及其它场景规则另计。

## Decisions

- 从固定SHA前驱文件读取38拥有区；逐字节保留战斗记录、列表、统计与所有其它字段。另用清晰的首根前声明变更场景、计时、任务/VM/脚本工作指针；保存完整覆盖清单和输入摘要，不运行期写派生结果。
- 使用原T0004容器和嵌套目录，原455060/4214F0自行选择条件与终局脚本；原条件VM执行，不借用旧工具的游戏函数桩。来源不匹配、未知PC、断言或越界写均拒绝并保留诊断。
- 不改IAT；Windows字符串比较等在原导入地址执行真实平台API。时间API首次采集实际回执，精确重放时显式使用采集平台时间输入，分开标注实际执行与采集回放；不可把平台回放称新的原生同寿命。
- 新增VM/脚本工作区纳入完整拥有区；守卫/根ABI沿用冻结算法并明确扩展代码/写入范围。观察器只读，CPU含57项记录。
- 独立预测事件条件/选择、请求字段、原条件脚本语义及结果数据；全内存由新实例重放保证，不声称独立预测整个VM内部字节。

## Risks / Trade-offs

- [旧0计时会触发到时分支] → 作为明确对照保留；正常时间为声明输入，不伪称自主战斗原计时已接通。
- [条件脚本包含额外依赖] → 查原目录/指令后执行原体，不能返回固定真值。
- [中性单位不在敌对集合] → 独立规则区分无敌对存活与玩家存活、死亡，不以存活单位总数判断胜败。
