# Design

## Context

参见proposal.md。复用已有独立班级/学生快照和4A4680原指令框架。4A2980从教师外部ID−101对应的100条工作记录筛选enabled且未blocked条目，用原映像模板的category−1和key−1构造三类工作列表。

## Goals / Non-Goals

**Goals:** 实际执行教师分支和工作表构造，纯函数复制即时、显式整理和评级结果；导出的模板字段作为来源规则，工作可用标记是声明输入。

**Non-Goals:** 日期解锁4A2BA0和完整教师来源迁移、课程选择/执行、原版指针捕获、教师成长、当前编班UI与存档。

## Decisions

- 新工具复用学生回放初始化，不修改旧工具或冻结报告。移除新实例4A2980桩，增加实际函数白名单和工作表写入守卫。鼠标、渲染和声音仍为明确边界。
- 只接受已核对教师117/118；其排序字段从原映像6F5088教师模板导出，不使用学生持久记录。当前两位教师排序键相同，三种模式保持输入顺序；班内移出到外部还执行现有学生排序，移到空班返回的学生不立即排序。
- 工作输入用每教师稀疏槽记录表示100槽默认零，保留enabled、blocked、work_id及槽号。源模板直接导出，规则字段哈希绑定实际类别/键；模型预先验证所有有效记录。输出只包含活动列表/计数和分页，未活动尾部不当作有效数据。
- 即时教师移动不评级班级；4A8B50选班会实际刷新工作表。显式后续4A5F40只在找到可用教师时选首班并刷新；若无教师则保留旧选择/工作显示，不能提前模拟后续UI清理。
- 模块提供独立move_teacher、select_group和reconcile，之后评级仍用旧纯函数。当前Campaign/UI不变，全部权限标记false。

## Risks / Trade-offs

- [活动/工作字段各分支不同] → 覆盖待命/班内、空槽/占用/同班/外部、adventure_gate两值和持有/释放，不统一抹平。
- [工作可用标记不等于剧情解锁事实] → 明确声明槽输入，导出规则只绑定原版模板，不授权当前教师/课程。
- [即时学生人数/派生成员及旧工作表可滞后] → 分开冻结各阶段，逐字段对照。
- [分页和100槽上限] → 覆盖10/11/12/13及99/100条、类别与禁用/阻塞记录。
