# Proposal

## Why

基础近战已有原命中、EFCT受击事件和HP写入，但8/9号受击请求、13号死亡请求、动画完成及单位移除尚未连续验证。需要把这些结果接入原单位更新，使攻击恢复和受击/死亡不再停在独立数值入口。

## What Changes

- 新实例重跑已验攻击/命中/HP前缀，在清理前沿用有效动画、记录和真实TLS资源，运行完整46B760单位更新根。
- 覆盖非致命轻/重受击恢复、攻击阶段22后续、HP0死亡请求/13号命令/动画/移除和原击杀统计；用真实地图及声明空状态/事件环境核对原帧顺序、计数与占用。
- 独立状态模型、新实例完整CPU/内存/轨迹和负测、相关回归、冻结父验收37份及递归保全，更新总规格并本地提交/归档。
