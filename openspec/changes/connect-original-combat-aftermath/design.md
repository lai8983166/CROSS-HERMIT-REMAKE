# Design

## Context

参见proposal。父HP执行器在清理前仍保有原动画/事件/真实TLS，适合在同一新实验寿命中继续。旧报告和已释放平台资源不能拿来直接运行。

## Goals / Non-Goals

目标为代表性基础近战后完整46B760单位更新：原动画结果写unit+4、计数推进、阶段22恢复、8/9受击恢复及13号死亡/移除/统计。原世界外层调度/全部单位帧、R3原线程原生同寿命和其他战斗类别不在本单元完成声明内。

## Decisions

- 私有子类在父HP之后、任何补充清理之前接入完整单位根；新所需地图/任务指针、门、空状态/事件与计时输入仅在首根前声明。原指令负责后续HP/命令/动画/计数/占用/统计，不使用计数或完成位宿主写回。
- 原46B760内的命令→动画→事件→HP/自然回复→死亡请求顺序保持，不按模型愿望重排。有限循环只选择下一完整根和停止条件，不能替代原体。
- 沿用真实CRT/TLS叶及原数学体，新增只读来源段/实际可写数据单独入所有权；不修改游戏/CRT代码、IAT或伪造返回。
- 先独立模型核对完整双单位/记录/动画池/伤害/popup/占用/统计，再新实例重放全部拥有区/57项CPU/实际轨迹；保存早期依赖失败，正式报告用新路径。
- 绑定父验收SHA并冻结其37个不可变工件，递归保全；总spec事实更新、专项/相关回归/严格检查后本地提交和归档。

## Risks / Trade-offs

- 全单位更新包含状态、自然回复、事件与地图依赖 → 声明可追溯的空状态/事件环境，执行原门控与原查询，不把空门当全类别支持。
- 9号命令有位移与浮点转换 → 沿用原数学实现，独立核对定点/占用和地形边界。
- 死亡先统计/动作再延迟移除 → 分别保留阶段边界和原记录值，不把HP0或13号请求称完成死亡。
