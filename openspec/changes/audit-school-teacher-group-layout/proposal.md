# Proposal

## Why

编班前必须证明教师如何登记，以及原版如何清理班级成员、重建索引和计算班级评级。当前返回演示没有教师，不能靠扩大ID范围直接开放编班。

## What Changes

- 执行Chapter012真实教师117加入指令，核对教师域、可用标记、重复登记和直接分班辅助函数。
- 独立执行教师/学生班级整理与评级函数，覆盖缺教师、不可用成员、重复学生、课程/冒险状态及好感阈值。
- 增加与原版输出匹配的隔离教师/班级数据模块、拒绝契约和验证文档。

## Capabilities

### New Capabilities

- `game-flow/school-group-layout`: 来源约束的教师登记、班级整理和派生评级数据。

### Modified Capabilities

无。

## Impact

新增审计工具、冻结报告、Godot隔离计算器及测试。现有返回演示、排序接口及其冻结证据不变。本阶段不把Chapter012插入当前返回剧情，也不开放未执行的拖放、课程选择或原版存档操作。
