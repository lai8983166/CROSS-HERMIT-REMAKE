# Design

## Context

参见proposal.md。已有school_teacher_group_replay和school_waitlist_sort纯函数，但现有返回会话无教师，不能直接把独立教师数据插入其目录。原版4A4680操作原始成员槽、待命缓冲和局部派生字段；完整整理不是该函数内部的必然步骤。

## Goals / Non-Goals

**Goals:** 用原指令独立验证学生分支，移植到独立快照，逐检查点保留原始行为，包括暂时滞后的计数。

**Non-Goals:** 教师移动、4A2980工作表、声音选择、完整原版鼠标捕获、当前剧情教师迁移、编班UI与存档。

## Decisions

- 复用TeacherGroupEmulator的源初始化与评级，增加4A4680/4A8BF0学生操作原函数白名单。释放输入、矩形命中、渲染、音效、随机语音选择与工作表为显式边界；不把语音函数4D48A0误当作关系修改。
- 输入是已整理且成员/待命一致的独立快照、来源组/槽/ID、目标组/槽与释放标志，以及当前学生职业/等级/属性排序字段。模型不读期望输出，动作输入从当前成员验证，未知教师分支拒绝。
- 原指令放手检查点与后续显式4A5F40/五班4A95F0分开记录；移植操作返回即时after，整理/评级仍由已有纯函数单独执行。持有鼠标时只保留真实反馈变化，不自动完成拖动。
- 报告保存每例初态，后继检查点以完整字段变化补丁表示，可无损重建；原生覆盖记录函数入口/关键指令与地址集合哈希，避免每阶段重复大快照。写入守卫限于班级原始/派生、待命缓冲、选择与任务拖动控制。
- 当前模块保持独立，成功/拒绝都无学校完整就绪、源实机或存档权限；现有会话/UI及冻结返回样例不改。测试以源CPU结果核对所有阶段并覆盖拒绝/输入隔离。

## Risks / Trade-offs

- [教师缺失目标被视为外部释放] → 覆盖班内与待命两种源，按原版记录，不以“拒绝”代替真实移出。
- [交换后原始计数或其他班派生成员暂时过时] → 单独核对即时与整理/评级检查点，禁止在即时结果偷偷修复。
- [鼠标命中和语音演出声明输入] → 每例保存边界调用信息，不声称完整学校交互。
- [排序与输入成员不一致] → 全局学生与全部班槽/待命必须一一分配，使用已核对的排序域及规则。
