# Proposal

## Why
真实原版已采集两个空格转换，但保留VM尚未接入这些输入。建立可在锁屏期间执行的来源回放，把原输入转换和完整任务接到同一保留逻辑状态。

## What Changes
- 重放冻结的完整任务报告，恢复三个编班案例的保留逻辑状态，使用已验证的76/77采集字节作为声明的GetDeviceState边界输入。
- 执行原键盘规范化与原完整任务，验证无输入等待、实际采集按下解除确认、松开及后继指令边界；不写PC、等待或派生按键位，不新增独立VM根。
- 独立复核全部新原指令/写入与自然栈，测试篡改拒绝、保护历史与存档，更新总规格实际边界并归档提交。

## Capabilities
### New Capabilities
无。
### Modified Capabilities
无。总规格要求不变，仅新增逆向工具/证据/文档，skip_specs=true。

## Impact
新增school_retained_keyboard前缀工具和证据。复用冻结任务和原生输入材料，不启动窗口、不发送新系统输入、不创建新GPU/OS资源；既有平台返回仅明确作为记录回放，不冒充新现场结果。R3完整外层线程/世界连接与Godot实现另计。
