# Proposal

## Why

来源新局已有教师101和学生3/4/9，但会话尚无编班操作，窗口也无法使用这些数据。接通来源移动规则和可操作界面，让用户直接在重制原型中编班。

## What Changes

- 在实际新局初始化和准备后的同一隔离CPU上执行成员移动、整理、评级，冻结来源样例。
- 扩展教师移动规则到明确的新局101域，保留Chapter012旧教师域。
- 会话接受带版本的成员移动，推导拖动来源并原子发布分开的移动/整理/评级日志。
- 主窗口增加新局编班入口、五班师生位置、待命名单、点选移动和返回/重开操作。

## Capabilities

### New Capabilities

- `game-flow/new-game-school-grouping`: 来源新局的会话编班与窗口操作。

### Modified Capabilities

无。

## Impact

新增隔离取证工具、样例、会话操作和学校面板，有限扩展教师规则及主窗口入口。旧返回会话保持其现有目录；存档、课程安排和完整新局剧情后续推进。
