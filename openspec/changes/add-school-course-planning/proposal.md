# Proposal

## Why

编班已可操作，课程解锁和教师列表已有来源规则，但还不能为班级选择课程。接通冒险/授课切换和课程安排，保持新局第0周事实，并提供明确标示日期输入的第4周排课示例。

## What Changes

- 执行原版班级模式菜单和课程点击函数，核对班级四个工作字段与评级。
- 新增来源课程安排纯模块和带版本的学校会话操作。
- 保留第0周新局；另建4月第4周课程示例会话，日期只是声明输入，不模拟周结算。
- 窗口增加课程页、班级模式与课程选择；示例和新局会话分别保留编班与课程安排。

## Capabilities

### New Capabilities

- `game-flow/school-course-planning`: 来源学校课程可用性、班级授课模式和可操作课程安排。

### Modified Capabilities

无。

## Impact

新增原指令证据、纯模块、会话接口和课程窗口；既有规则文件与冻结证据保留。课程完成/成长结算、实际周推进、剧情和存档后续推进。
