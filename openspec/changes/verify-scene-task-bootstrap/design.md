# Design

## Context

沿用冻结自有Job启动/正常关闭观察器和仅写新分配内存的x86调用桥。场景任务大小1194F0h、主虚表59A430，回调451670先初始化/让出后才进入场景状态分派。

## Goals / Non-Goals

Goals：完整原派生构造/私有注册/禁用扫描/移除/析构实际执行；明确验证422360与延迟tick的字段/同步协议。
Non-goals：不运行未满足场景资源前提的完整451670/4539B0，不把独立yield根与实验事件释放说成原CRT回调/调度器恢复，不修改保留检查点或声称R3完成。

## Decisions

- 扩展冻结桥的派生客户端，数据区独立分配2MiB容纳原对象；新增入口严格白名单、对象/参数核验，原桥及旧证据不改。生命周期源代码/IAT前后核验，实际API生成字段按来源归类。
- 原451170构造后实际4216C0注册到独立管理器；422560置禁用、4217C0扫描不得执行回调或改变完整对象。以421D50解除注册、451470析构，原manager析构；不触发场景回调的资源/文件/全局流程。
- 协作探针独立新进程/基类节点，原manager/节点构造注册，节点事件由实验实际CreateEvent/DuplicateHandle提供并明确标为声明的自有平台输入。原422560置active1，异步原422360(delay2)真正阻塞；原4217C0两次将delay2→1→0，线程仍未结束；实验实际SetEvent释放节点，原函数返回，清除yield标志。只验证该协议，不冒充原CRT工作线程。
- 完整对比对象阶段字节；构造阶段核对来源字段/资源身份，不将其描述成整个构造器逐指令独立重放。记录原函数体/虚表/IAT、ESP、线程实际等待/退出和补充资源清理。

## Risks / Trade-offs

- 原构造会更新专用静态上下文 → 只在自有新原版进程运行，原析构与正常关闭均需真实返回；旧存档/历史证据前后核验。
- 异步桥参数区不能并发复用 → yield线程等待期间使用独立参数槽/入口；所有入口退出后才释放新分配内存。
- 真实句柄与未退出线程 → 保留实际状态，异常不提前释放正在执行的代码/数据，交由明确记录的自有Job清理；失败不验收为正常结果。
