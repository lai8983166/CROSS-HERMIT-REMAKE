# Proposal

## Why

R3调度器寿命已验证，但基类空回调不包含场景派生对象来源、注册和协作等待。需核实真实场景任务构造链/虚表和注册契约，并实测422360的等待及延迟计数，避免把4539B0错误当成线程入口。

## What Changes

- 固定451080工厂、451170构造、59A430虚表、451670线程回调、451A60→4539B0状态分派和422360让出/恢复来源。
- 自有原版运行时中执行独立场景对象的原构造、原注册、禁用跳过、移除及析构，对零/脏缓冲进行完整阶段字节比较和资源清理观察。
- 单独以明确的原422360根调用、真实自有事件和原调度器延迟tick核实协作等待/恢复；外部释放明确标注为实验驱动，不称原CRT回调或场景推进。
- 更新总spec与交接，完成回归/历史/存档保全后归档。

## Capabilities

### New Capabilities

无，研究工具与现有R3要求的实现，skip_specs。

### Modified Capabilities

无。

## Impact

仅新增场景bootstrap审计工具/证据。冻结R1/R2/任务帧/调度寿命证据不改；原代码/IAT/用户存档不改。完整场景回调、保留VM与49E540/世界/物理输入连接另计，R3整体仍未完成。
