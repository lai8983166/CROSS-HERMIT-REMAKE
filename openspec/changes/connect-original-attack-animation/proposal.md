# Proposal

## Why

## What Changes

- 使用原四类近战动画及静态动作表，在声明已加载资源缓存上执行原单位动画绑定/初始化和完整攻击命令。
- 执行完整40A100根，独立核对子动画、帧计数、攻击数据队列与结束；原482A30对无效目标自然回收，对有效目标保留自然调用栈停在48AAE0首指令前。
- 全单位/动画/事件池独立模型、新实例全内存/CPU/轨迹及负测、父40份冻结和递归保全通过后同步事实、提交、归档。
