# Design

## Context

参见proposal。复用冻结LiveMachine的新实例原交战/世界/事件，避免战后快照装载。终局工作全对象还需2490以后的字段；旧三个寄存器字节的映射不够，不能越界写入。

## Goals / Non-Goals

**Goals:** 中性/到时两例原选择之后，同对象自然暂停，原117淡入和118淡出分别完整结束并验证工作等待解除；不活动调用及末次之后调用作为对照。

**Non-Goals:** 不用补充根模拟完整VM脚本顺序，不改PC绕过表现，不称任务调度、真实图像/输入或退出/奖励完成。

## Decisions

- 新执行器私有扩展原守卫/根ABI/内存快照算法，固定冻结工具不变；WORK扩展为有界完整24C0字段及整页拥有，初始空工作字段为明示夹具，原497800初始化。
- 原455160的三个菜单开关经TASK+60访问WORK+20E8/216C/2230；新夹具首根前将该成员声明为WORK，修正前驱从未消费暂停时仍写VM地址的占位布局。VM仍使用原全局7D7C28，不在运行期修补此指针或派生开关。
- 在真实首次终局事件返回后执行一次完整46B470，自然4678C0消费暂停；再显式调用T0004所选脚本PC44的117及末尾118真实处理器。参数含原命令指针/声明长度，所有操作都保留独立根边界；不写或伪造VM执行PC。
- 每个处理器后循环原497AA0/498310，至少保留一次不活动/结束后继，原4977A0清VM等待；记录完整拥有区、57项CPU、所有原指令和写摘要及关键写轨迹。
- 独立模型核对暂停精确字段、原x87/ftol转换和每步进度/剩余/状态、自然解除来源；新实例完整重放，采集时实际Windows叶与TLS，精确回放仍明确使用采集时间输入。
- 冻结上轮验收清单26项不可变产物及固定验收SHA，递归保全此前原资料；失败报告和采集只写新路径。

## Risks / Trade-offs

- [淡入/淡出最后数值受截断影响] → 从原常量和ftol算法预测实际数值，不归一化到0或满值。
- [暂停暴露交互字段依赖] → 精确扩大来源对应范围并执行原体，不关闭门/伪造返回。
- [补充处理器被误认为正常脚本进度] → 报告PC仍由原绑定保留，明确118为独立契约实验；真实VM和表现资源继续作为下一连接段。
