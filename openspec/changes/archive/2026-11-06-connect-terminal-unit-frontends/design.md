## Context

父source5/proof7为当前接受基线；大文件仅保留该来源与一份副本，历史退役项不得当作仍存在。见proposal动机及docs/evidence-retention.md。新目标记录使用原静态profile11，但源职业9与旧实验职业不同，必须明确实验职业覆盖，不能声称恢复完整原场景输入。旧动画控制对象只有声明元数据，图像包未真实绑定；原加载将选择实际可用槽，不预设为0。

## Goals / Non-Goals

目标是在最早构造输入阶段执行原B0派生、明确后续实验字段覆盖，保留MP/恢复等原派生结果；完成当前单位真实资源绑定并跨过旧前端边界到原首个协作等待入口。使用两个从构造开始的新当前原生寿命及独立原指令/ABI/内存/CPU/资源验证。

不恢复旧线程/TLS，不在终局修改记录或伪造getter/HUD返回；不以当前有界资源方法根声称完整原场景初始化。原等待体/结果消费、实际Draw/Present、完整退出与奖励学校继续待验。

## Decisions

- 新记录根及源profile独立原指令验证；应用已存在的明确实验身份/职业/HP/位置/阵营等输入时逐字段列账，不用整个旧零B0覆盖。来源生成与当前战斗输入、实际前向分开记录。
- 旧轨迹不能直接继承成功：新记录改变读值/原写入及累计摘要，必须从新构造重放。冻结工具只复用其原机器算法；任何观察或输入合同适配须逐项审计，不改旧证据，不把重基后的摘要包装成旧摘要一致。
- 单位图像来自当前职业对应的原DxAnim文件及调色板/标记，原图像包构造、槽选择、全体记录/整pitch/padding和清理由原代码与真实平台执行。
- 新证据格式以父source5为固定基线：对象引用保留父节点，变化数据分块二进制、SHA256寻址去重。读取时校验基线身份及块摘要，严格无损还原供现有机器验证器消费的完整数据。禁用新未压缩全案例文件，失败保存首差和有界现场。
- 预算：本轮主来源元数据及新块包合计不超过128MiB，一份恢复副本后总量不超过256MiB；写入达到上限立即停止并报告，不自动扩大预算或追加全量父历史。测试需包含还原一致、缺块/损坏/错误父拒绝和硬上限。

## 2026-11-04 接入核对

- 两个当前终局案例实际都采用职业1；原profile11的职业9先明确覆盖为1，再由原4DFC20派生B0并逐字段应用旧实验声明。职业3的B0/资产合同单独静态与有界核对，不将其称为本轮已完成原生终局案例。
- 目标和行动者的调色板不同，必须保留两份真实单位缓存。两者使用独立且完整的unit身份表和分离地址池；旧终局身份表保留其原域与游标。验证时合并两表，不隐藏或删除单位身份。
- 原7A4A00路径拥有者与renderer MAIN分开，避免4500B0工作区覆盖group20计数。早期原heap/lock两根移到首次单位绑定之前，原后段只删除这两个重复调用表达式，其余旧宿主程序保持。
- 证据采用完整初态、实际API边界字节与原指令重放，保存一个完整前向内存停点。旧观察器的重复逐帧全内存不另长期保存。固定source5作为父验收引用，原EXE作为可校验的静态分块基线；不解压/复制整个父案例树或恢复历史guest/native状态。解码无损恢复本轮完整执行见证，独立执行重建全部交易内存、57项CPU及累计字段。
- 正式每例块包与元数据硬上限60MiB，两例120MiB；一份恢复副本后最多240MiB，给小报告/构建记录留16MiB。收尾按全部实际本地文件核算256MiB目标，临时开发包在被正式见证替代后按清单退役。
- 独立重放除了根ABI，还约束初始原heap/lock/WORK/两单位绑定/细网格插入/world-event根次序。新根只在真实RETURN、声明键盘片段末端或已核对前向WAIT后清理阶段允许；中途停点只能从实际EIP继续。源与全新实例还须逐交易比较根/续跑、完整CPU/内存摘要和累计字段。
- 只读原生sync/readback也必须记录其实际指令边界，不能等缓冲区被后续原指令改变后再核验。lstrcmpA独立执行真实Windows排序，不以ASCII字节序代用；COMMON的Dm-No-MakeTex长度查询独立于GDI调用序列。

## Risks / Trade-offs

- 新记录字段使前驱摘要改变 → 独立复核输入与原控制流，重建全寿命证明，不放宽旧摘要比较冒称复用。
- 原槽/加载链暴露其它依赖 → 先实测定位，保持等待入口为验收目标；范围需要实质改变时明确说明，不静默减少任务。
- 旧报告仍很大且解析慢 → 核对固定父验收身份，不解析或复制全量父案例；新增磁盘只落本轮执行见证，保持原接受来源与一份副本不变。
- 去重格式影响可复核性 → 完整还原与损坏拒绝测试先通过，再接正式来源/证明。
