# Design

## Context

见proposal.md。上轮验收固定了六分支的原CRT域/完整读取和403BD0前状态。历史2026-10-13原生样本已有256×512纹理四次真实COM回执及全像素读回，但其旧分配/memcpy/free为明确原语，不能当成本轮原函数执行证据。

## Goals / Non-Goals

Goals: 在同一个新堆锁寿命内，执行保留IMAGE前缀、原纹理体/512行原memcpy、原缓冲释放及4CC0D2自然返回；补充调用原容器清理并独立验证所有原代码、状态和接口来源。

Non-Goals: 新原生GPU、未修改旧检查点恢复、历史堆重建、原handler动画/任务返回、外层世界、Godot或R3/R6整体完成。

## Decisions

1. 重用已验cold初始化/335字节有限投影与自然IMAGE入口；在新助手内重新执行完整原文件与分配前缀，绝不复用上轮已销毁资源。
2. 固定旧原生验收及live-v3报告SHA，独立重新核对其COM结果、真实读回与资源内容；仅投影四个原纹理API响应到新逻辑纹理域。device/texture/bits都不传Windows，不修改代码/IAT。
3. 原56D4D0逐指令执行，观察512次源/目的/长度参数且完整比较像素；原428AD0自然释放文件缓冲，保持向量存活。未初始化记录填充字节仍为CD，其他旧纹理/脚本区不变。
4. 边界后以明确补充根调用原41F4E0(slot32)，原析构及原free摘除向量并清空表；Release仅回放历史平台关闭计数，不冒充历史原调用点。再原锁/堆销毁，助手零资源正常退出。补充清理不计IMAGE或handler返回。
5. 新独立重放器复核新原指令/写入、每一步全CPU/内存、旧接口映射/所有权、源像素/行复制、原统计及清理。只追加新工具/证据，历史证据保持。

## Risks / Trade-offs

- 历史接口记录并非本轮实际GPU → 明确recorded_GPU_only、新GPU=false，不产生新的显示结果声明。
- 原生旧内存原语验证较弱 → 仅复用已验接口回执，本轮CRT/memcpy/析构全部原代码执行并独立重放。
- 新堆不拥有旧对象 → 严格源分配所有权，只释放本轮两块；旧历史仍未恢复。
- 清理后向量/纹理失效 → 保留返回前状态证据；不得把已清理实验当作活检查点继续。
