# Proposal

## Why

The accepted retained portrait continuation stops before CreateFontA. R3 needs a source-backed connection through actual name pixels without requiring an unlocked interactive desktop.

## What Changes

- Continue all six accepted logical branches through original font and raster code to the natural original texture-upload entry.
- Use fresh offscreen GDI resources with explicit translation of the historical measurement-DC token. Execute game functions, including their CRT and DC accessor, from pinned source bytes; do not patch the IAT or substitute game-function returns.
- Independently replay recorded platform calls and check complete memory/CPU, raster geometry and name pixels. Exercise all 21 catalogued source names through a separate offscreen corpus experiment.
- Preserve old evidence, saves and checkpoints; update the master progress record and archive this finite change after three implementation tasks.

## Capabilities

### New Capabilities

None. This is research tooling and evidence under existing reverse-engineering/completion requirements; skip_specs is explicit.

### Modified Capabilities

None. R3 and R6 requirements and target date remain unchanged.

## Impact

New tools/tests/docs and immutable evidence only. No Godot, game installation, old helper or checkpoint edits. No original game window, foreground manipulation, OS input or GPU device. The historical measurement-DC token is translated only at the platform boundary to a fresh owned memory DC; this is a declared resource reconstruction, not the same native lifetime. GPU upload, image loading, outer-thread/world integration, six short command encodings and R3/R6 completion remain outside this unit.
