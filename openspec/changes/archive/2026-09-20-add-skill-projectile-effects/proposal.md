## Why

当前重制版只有普通攻击演出，技能施放仍缺少施法者动作、释放/弹道阶段和命中动画；现有特效管线还错误地把独立 `##E` 档案及攻击表 `hit_effect` 当作运行时视觉映射。逆向已经确认原版实际加载 `EFCT.BIN`，并由技能明细表驱动多阶段演出，因此需要先建立忠实的数据链和一个可目检的纵向样例。

## What Changes

- 从原版技能明细表导出动作、持续施法特效、释放/弹道特效、同步/目标阶段、命中动画及范围形状字段，并保留全局动画 ID。
- 从 `EFCT.BIN` 导出四个程序块、帧资源和全局动画 ID 映射，支持一次性时间线、空白同步时间线与由外部阶段终止的持续循环。
- 为单位精灵导出 action 11～16 的八方向施法、释放和恢复映射，不再只支持 action 3/5。
- 增加数据驱动的技能演出状态机，按施法、释放/弹道、同步、命中和恢复顺序推进；首轮以技能 29 建立可自动测试、可目检的完整纵向样例。
- 纠正攻击表 `hit_effect` 的语义：它是玩法效果分派 ID，不直接选择视觉资源；视觉命中动画来自技能明细表或原版通用命中表。
- 缺失动画、空白同步动画或未支持的玩法效果必须安全降级，不能阻断战斗确定性或回退到错误通用特效。

## Capabilities

### New Capabilities

- `battle-sim/skill-casting`: 数据驱动的技能演出事件、阶段推进、技能 29 纵向样例及确定性回放行为。

### Modified Capabilities

- `assets/attack-effects`: 将战斗特效源和映射改为 `EFCT.BIN` 全局动画 ID，并区分持续、同步、命中动画与玩法效果 ID。
- `assets/unit-sprites`: 增加 action 11～16 的原版八方向施法、释放和恢复动作映射。

## Impact

- 影响 `tools/dxanim_lib.py`、特效/表格/单位动画导出器及其测试。
- 新增或更新 `prototype/data` 与 `prototype/assets/fx` 中的派生资源。
- 影响 Godot 战斗事件、单位状态与渲染层；需要新的技能演出测试和目检入口。
- 不在本变更中实现完整技能选择 UI、全部 99 个技能的语义标注、伤害/状态效果全量还原或自动追踪型弹道物理。
