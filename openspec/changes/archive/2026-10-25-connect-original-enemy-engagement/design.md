# Design

## Context

见proposal。冻结父工具已验世界、动画、物理判定和单位收尾；攻击者为玩家、目标为敌方，停止请求阻止阶段24后的原决策。需要私有继承以保全已验资料。

## Goals / Non-Goals

验证敌方阵营4的普通9F/A0策略0、19号警戒、最近敌目标搜索、两次完整攻击和恢复后重新决策。玩家目标声明命令5，HP容量足够两轮存活；不宣称双向AI战斗、全场景加载、所有策略/技能/死亡类别、胜败或外层原生同寿命完成。

## Decisions

- 保持UNIT为攻击角色、TARGET为受击角色，首次根前互换阵营为4/0；目标/技能初始-1。这样可复用已验受击与动画角色，不把玩家行为冒称敌方；模型按实际阵营重新计算列表和视野。
- 原绑定/空路径包初始化之后只调用完整世界根；首次当前命令2由原待机自然超时请求15，15自行请求19，19周期扫描并请求6。阶段24自然清除旧目标/技能并请求15，禁止宿主提交攻击或停止请求。
- 四职业各完成两轮恢复，另加完整后继帧验证重新决策；对照运行96帧，不能产生攻击请求或命中。每例最大384世界帧，超时失败。HP、种子、原函数调用者逐帧记录。
- 私有扩展原代码准入范围并绑定来源SHA；复用冻结守卫的原逻辑及无损4096字节分页。独立模型只读原常量和输入，不以实际报告喂入期望；37拥有区和57项CPU/指令写轨迹另作实际新实例重放。
- 以最新验收清单冻结52份父产物并递归检查原资料；专项破坏测试、相关回归、严格规格后更新总规格事实，提交并归档。

## Risks / Trade-offs

- 阵营变化影响列表、视野、目标过滤和攻击收尾 → 完整字节逐阶段比较，显式敌对矩阵输入，对照拒绝搜索。
- 待机每帧抽阈值会改变命中与动画结果 → 独立推进全部游戏/CRT随机数，当前HP与命中记录逐次核对。
- 两轮样本仍是有限类别 → 文档保留高级/特殊AI及主线集成缺口，不提升R4整体完成状态。
