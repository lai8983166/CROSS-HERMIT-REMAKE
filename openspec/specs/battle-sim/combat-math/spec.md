## Purpose

提供战斗数值核心的可测试实现：单位战斗字段、进战斗前的派生上限、伤害/命中三式、ENGAGE TIME——语义与原作逆向结论（蓝图 §4）一致，作为战斗模拟器与后续系统的基础层。

## Requirements

### Requirement: 单位战斗字段模型
战斗单位以纯数据对象表达，至少包含：七属性（力/敏/感/活/智/耐/精）、职业 id、等级、当前与上限 HP/MP、回避、装甲、魔抗、精神抗性。字段命名沿用逆向档案语义（character_growth.md §1.3）。

#### Scenario: 从属性构造单位
- **WHEN** 以一组七属性 + 职业 id + 等级构造单位
- **THEN** 对象可读回全部上述字段，缺省字段（如回避/装甲）为 0

### Requirement: 派生上限合成
给定单位与职业系数（读 `data/job_table.json`），按原作公式整数运算派生三项上限：
`HP_max = clamp((耐×3+力+敏+修正)×hp_coef/100, 1, 999)`；MP_max 与精神系同构（系数取 mp_coef / spirit_coef）。除法为 C 语义向零截断。

#### Scenario: 合成 HP 上限
- **WHEN** 耐=10、力=10、敏=10、修正=0、职业 hp_coef=100
- **THEN** HP_max = 50

#### Scenario: 钳位下限
- **WHEN** 全属性为 1 且 hp_coef=1
- **THEN** HP_max = 1（公式结果不足 1 时钳到 1）

### Requirement: 物理伤害与命中（原作 4824D0 语义）
输入攻击参数（威力、浮动、命中值）与防御参数（回避、回避系数、防御、防御系数），随机数由注入的 RNG 提供：
```
c = 命中 − (回避×回避系数)/100 − rng 0..99
防方回避为 0 或 c≥150 → m = max(c,150)；否则若 rng∈(4,94] 且 c<0 → MISS；否则 m=100
威力 p = 威力 + (浮动>0 ? rng%浮动 : 0)
伤害 d = p×m/100 − (防御×防御系数)/100
m==100 时 d<1 → 0；m>100 时 d<1 → 1
```

#### Scenario: 命中溢出倍率档
- **WHEN** 命中=200、回避=0、RNG 固定种子使两次 roll 均为 0、威力=100、浮动=0、防御=0
- **THEN** m=200，伤害 = 100×200/100 = 200

#### Scenario: MISS 分支
- **WHEN** 命中=10、防御方回避=50、回避系数=100、RNG 使命中 roll=50（>4 且 ≤94）、c<0 成立
- **THEN** 结果为 MISS（无伤害）

#### Scenario: 普通命中可零伤
- **WHEN** m=100、威力=10、防御=20、防御系数=100
- **THEN** 伤害 = 0（10−20<1，钳 0）

### Requirement: 魔法与固定伤害
魔法伤害按 `抗性 = 100 − 魔抗 + 修正` 缩放；固定伤害直接输出定值（不受防御/抗性影响）。两者与物理式共用钳位语义。

#### Scenario: 魔法抗性
- **WHEN** 基础威力=100、魔抗=40、修正=0
- **THEN** 伤害 = 60

### Requirement: ENGAGE TIME 计算
`engage = 修正h×3600 + 表[clamp(等级,0,50)]×60 + 修正s`，结果 clamp(1, 356400)。表来自 `data/engage_table.json`（分钟/等级）。

#### Scenario: 低等级封顶
- **WHEN** 等级=1、修正均为 0
- **THEN** engage = 356400（表值 5940 分钟 ×60 恰为上限）

#### Scenario: 满级
- **WHEN** 等级=50、修正均为 0
- **THEN** engage = 32400（540 分钟 ×60）

### Requirement: 可测试性与确定性
所有公式函数为纯函数（或仅依赖注入的 RNG）；RNG 可注入种子，使同参数同种子输出恒定。测试经 `godot --headless` 可运行并给出通过/失败退出码。

#### Scenario: 确定性
- **WHEN** 同参数同种子连续计算两次物理伤害
- **THEN** 两次结果（含 MISS 判定）完全一致
