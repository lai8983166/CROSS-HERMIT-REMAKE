# Attack Effects Specification

## Purpose

让重制版按照原版数据播放单位攻击动作，并且只在攻击条目明确指定且已有映射时播放独立的 `##E` 特效，避免用错误的通用特效替代原版演出。

## Requirements

### Requirement: 单位八方向攻击动作

系统 SHALL 从原版单位动作表导出 action 5 的八方向映射，并在单位执行普通攻击时按照攻击目标方向选择对应时间线及镜像标志。

#### Scenario: 普通攻击动作
- **WHEN** 单位向相邻目标执行普通攻击
- **THEN** 单位朝向目标并从首帧播放对应方向的 action 5 时间线一次

#### Scenario: 攻击结束
- **WHEN** action 5 时间线播放完毕且尚未发生下一次攻击
- **THEN** 单位视觉回到对应的待机动作，攻击时间线不得循环

### Requirement: 攻击事件携带原版效果标识

战斗攻击或技能事件 SHALL 包含攻击条目 ID、玩法效果 ID、独立视觉动画 ID、攻击起始帧、双方格坐标、命中结果与伤害。玩法效果 ID 来自攻击表 `hit_effect`，独立视觉动画 ID 来自技能明细表或通用命中表；事件记录不得改变战斗判定结果。

#### Scenario: 样例职业普通攻击
- **WHEN** 职业 1 或职业 3 使用其原版默认普通攻击
- **THEN** 事件分别记录攻击 101 或 103、玩法效果 ID 0，且不凭该字段生成独立视觉特效

#### Scenario: 技能视觉标识
- **WHEN** 技能明细表给出非零释放、同步或命中动画 ID
- **THEN** 事件按阶段保留相应全局动画 ID，并与攻击表玩法效果 ID 分开

### Requirement: 外置特效仅按明确映射播放

系统 SHALL 仅按事件中明确的全局视觉动画 ID 或战斗配置提供的显式职业覆盖播放外置特效。系统 MUST NOT 将攻击表玩法效果 ID 当作视觉动画映射，也不得为未映射攻击应用通用默认特效。

#### Scenario: 无外置特效的普通攻击
- **WHEN** 普通攻击没有独立视觉动画且没有显式职业覆盖
- **THEN** 系统只播放单位攻击动作，不绘制 `01E#21` 或其他外置特效

#### Scenario: 已导出全局动画
- **WHEN** 事件的非零全局动画 ID 在特效表中存在有效映射
- **THEN** 系统按事件指定阶段和锚点播放对应时间线

#### Scenario: 已映射外置特效
- **WHEN** 事件给出已导出的非零全局视觉动画 ID
- **THEN** 系统在事件指定的源、目标或单位锚点播放对应时间线，并在该阶段结束后移除

#### Scenario: 缺失或无效映射
- **WHEN** 特效表、映射或资源缺失
- **THEN** 系统不播放该外置特效且不报错，单位动作和战斗逻辑照常运行

### Requirement: 特效档导出与复用

战斗特效导出管线 SHALL 以原版运行时加载的 `EFCT.BIN` 为权威资源，复用共享 DxAnim 解码器，输出四个程序块、全局动画 ID 映射、帧和时间线数据；所有导出的帧引用 MUST 位于 `EFCT.BIN` 的帧范围内。

#### Scenario: 全局动画映射
- **WHEN** 导出全局动画 ID 2042 或 3027
- **THEN** 系统分别解析为 `EFCT.BIN` 的 block 1 animation 42 与 block 2 animation 27

#### Scenario: 持续时间线
- **WHEN** 动画由外部技能阶段负责终止且其控制流持续循环
- **THEN** 导出结果保留可播放的循环起点，不因解释步数上限而失败

#### Scenario: 特效档完整性
- **WHEN** 运行特效导出器
- **THEN** 帧数与容器一致，时间线引用有效，并保留复合图层、持续时间、镜像和空白同步步骤

#### Scenario: 导出特效档
- **WHEN** 运行特效导出器处理 `EFCT.BIN` 中已支持的全局动画
- **THEN** 导出帧数与容器一致，动画号解析到正确程序块，且产物可由运行时按全局 ID 读取
